# 模型生成过程追溯与回答证据验证 Agent

自然语言处理课程期末项目，首版面向通用事实性回答。包含两项核心能力：追溯生成时可观察的提示、上下文材料与工具调用；生成后独立寻找证据、核验陈述并按需修订。生成材料支持与事后核验分别展示，原生成链保留，修订形成派生记录。

缺少原始记录时无法还原生成过程，仍可执行事后核验；不根据回答编造提示、来源或内部推理。

RARR 是候选参考方法，SAFE 和 FActScore 等可作为核验与评估参考；具体方法仍需研究确认。当前已整理项目资料并建立目录骨架，尚无可运行代码；模型、检索服务、界面框架和数据集待确定。

## 后续放置约定

- 研究论文后确定模块接口与判定规则，并记录参考方法与实际实现之间的差异。
- 界面和实验脚本复用核心流程，避免重复实现。
- 核验结果区分有证据支持、证据矛盾、证据不足与来源冲突；最终分类及定义研究后确认。未检索到证据不能直接判为错误，检索支持也不能直接等同于现实事实已被证明。
- 配置与提示模板分开管理；密钥保存在本地 `.env`，不写入代码或日志。
- 原始数据保留来源与日期；评测集记录样本ID、版本、标注规则及划分。
- 每次运行使用独立的 `outputs/<run_id>/`，保存输入、配置、模型版本、提示版本、随机种子、证据、中间结果、耗时与调用成本。
- `experiments/` 放实验定义，`outputs/` 放生成产物，正式汇总与错误分析放 `reports/`。运行产物默认不提交，共享时显式选取脱敏结果。
- 课件快照用于离线查阅与核对来源，是否作为检索语料尚未确定。
