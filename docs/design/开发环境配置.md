## 2. 配置文件与复用命令

- `configs/default.toml`：本机127.0.0.1:8000、单worker、SQLite WAL/FULL/外键、本地资料范围、BM25参数、阶段预算与超时。它是后续业务实现要读取的配置，现阶段检查脚本只解析并检查关键本机约束，不代表全部配置已经由业务程序执行。
- `.env.example`：可提交的模型字段模板。
- `.env`：已创建的本地配置，模型地址/名称/密钥/上下文与输出上限留空；不会覆盖已有本地密钥。
- `data/reference/`：预留独立参考资料目录，目前没有真实语料；目录内资料默认Git忽略。
- `scripts/check_environment.py`：无付费调用的本地环境检查。
- `scripts/setup.ps1`：从锁文件同步并执行检查，已有`.env`保持不变。

在项目根目录的PowerShell执行：

```powershell
# 同步锁定依赖并检查；不需要先激活虚拟环境。
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1

# uv在当前终端可用时也可以分别执行：
uv sync --frozen
uv run --frozen python scripts/check_environment.py
uv run --frozen ruff check .
uv run --frozen ruff format --check .
```

脚本的ExecutionPolicy参数只作用于这次PowerShell进程，没有持久修改系统脚本策略。后续新增依赖应显式更新 `pyproject.toml` 和 `uv.lock` 并重新检查；日常使用 `--frozen` 防止意外升级。

## 3. 模型接入仍需填写的字段

在本机 `.env` 编辑以下值，不在聊天中粘贴密钥：

| 字段 | 填写内容 |
|---|---|
| LLM_BASE_URL | 所选兼容服务的API基础地址，通常由服务文档指定 |
| LLM_MODEL | 真实可调用的模型ID |
| LLM_API_KEY | 该服务的密钥 |
| LLM_CONTEXT_TOKEN_LIMIT | 服务实际支持的上下文限制 |
| LLM_MAX_OUTPUT_TOKENS | 服务实际支持的单次最大输出限制 |
| LLM_ALLOW_NO_API_KEY | 默认false；只有明确配置无密钥服务时才设true |

本次没有注册服务、复制其他项目密钥、调用付费模型或选择计价表。即使字段齐全，检查脚本也只显示字段是否存在，不验证供应商连通、输出上限生效、结构输出质量或费用。真实能力探针属于后续M0，需用所选服务与明确预算执行。
