核心问题：一词一标签，但标签彼此牵连环节一 · 课程导入
回收第 4 讲：分词就是贴标签
南 京 市 长 江 大 桥 B M E B M M E B = 词首　M = 词中　E = 词尾 切分分歧 = 标签序列分歧

当年靠词典 + 最大匹配；今天用序列模型统一处理——把 M 换成 I，就是英文 NER 的那套编码。

立论之本：标签之间有硬约束
… exports to Iraq O O I-LOC ← I 前面没有 B，非法！ B-PER 后面合法的只有：I-PER 或新实体的 B-X 绝不能是 I-LOC

逐词独立打分时，模型根本不知道左邻标签是什么——非法序列照样输出。

两个必须整句看的问题

歧义：Time flies like an arrow.（time 是名词还是动词？flies 是动词还是名词？）——单个词拿出来没有答案。
组合：20 个标签 × 30 个词 = 20³⁰ 条候选标签序列，枚举绝无可能，必须结构化地搜索。

本讲全部内容都围绕这一句：目标不是 n 个独立决策，而是一条受约束的、整句最优的标签序列。

任务定义与结构化预测环节二 · 知识点讲解 · 考点
输入 x = ( x₁ , x₂ , … , x_T ) 观测序列（词 / 字 / 子词） 输出 y = ( y₁ , y₂ , … , y_T ) 标签序列，|y| = |x| ← 等长约束 目标 ŷ = argmaxy ∈ Yᵀ P( y | x ) 整句联合最优，不是逐位最优
理由一：硬约束被无视
# 逐词独立分类（假想）：“贵”被误判为机构开头 郭 贵 冰 入职 华为 B-PER B-ORG I-PER O B-ORG ← 自相矛盾，非法序列

独立分类器不知道上一步标了什么，所以非法序列照样输出。而标签合法性是确定性规则，不是概率偏好。

理由二：标签搭配偏好被浪费

“限定词 → 名词”的概率远高于“限定词 → 动词”；“介词 → 限定词/名词”常见，“介词 → 动词”罕见。

这类标签之间的转移统计是极强的信号，但独立分类器用不上——它只看当前词与上下文词，看不到邻居标签。

组合爆炸：不能枚举，但可以动态规划
20 个标签 × 30 个词 = 20³⁰ ≈ 10³⁹ 条候选序列 但标签只在相邻两列之间有依赖： → 动态规划 O(T · K²)，K=20、T=30 时约 1.2 万次运算
这就是第 3 讲的动态规划，第三次出场

第 3 讲：编辑距离——在网格里填表求最优编辑路径。

今天：Viterbi——在同一类网格里填表求最优标签路径。同样是“填表 + 回溯”，只是格子里的语义变了。

一句话：序列标注是结构化预测（structured prediction）在 NLP 里最基础、最典型的形态。

中文没有屈折后缀，对应手段是构词语素（“性、化、度”提示名词或形容词）与虚词搭配（“的”后多为名词）。

证据 B：上下文线索（搭配）

① 句法位置
限定词（the / a / this）后面必然接名词：the back door → NN。

② 前后词的词性搭配
“介词 → 限定词/名词”极常见，“介词 → 动词”罕见；情态动词（will / can）后面必是动词原形：will back → VB。

③ 词义搭配偏好
“hurt his ___”里的词更可能是身体部位 → back 取 NN。

这两类证据，正好对应 HMM 的两张概率表

词内部线索 → 发射概率 B：P(词 | 标签)——“名词这个标签发出 back 的概率有多大”。
上下文线索 → 转移概率 A：P(标签 | 前一标签)——“限定词后面接名词的概率有多大”。

所以 POS 建模的关键问题变成：如何把这两张概率表组合起来，选出让整句概率最大的那串标签？

两大假设：算法可行的前提，也是能力的上限环节二 · 知识点讲解 · 考点
假设 ① 齐次一阶马尔可夫
P( tᵢ | t₁ … tᵢ₋₁ ) ≈ P( tᵢ | tᵢ₋₁ )

当前标签只看前一个标签——与第 7 讲的 bigram 完全同构，只是建模对象从「词」换成了「标签」。

代价：长距离标签依赖丢失。例：These 决定后面必须是复数名词，但一阶模型看不到句首的 These。

缓解：高阶 HMM（trigram）。参数从 N² 涨到 N³——45³ ≈ 9.1 万，稀疏更严重。

假设 ② 观测独立
P( wᵢ | x 全部 , y 全部 ) ≈ P( wᵢ | tᵢ )

当前词只由当前标签发射，与前后词、前后标签都无关。

因果方向：HMM 认为“标签决定词”——所以要先定标签，再由标签生成词。

代价：词与词之间的相互影响被丢掉。而消歧最需要的恰恰是这种影响（“东北大学”后面常跟“软件学院”）。

“假，但有用”

这两个假设在真实语言里显然不成立；但正因为它们成立，HMM 才能把指数级的路径搜索变成 O(T·N²) 的动态规划。用近似换可计算性——这是统计 NLP 里反复出现的取舍。

必须能背：一阶马尔可夫（标签只看前一个标签）+ 观测独立（词只由当前标签发射）——HMM 的强与弱都由这两条决定。

无监督：EM 与 Baum-Welch

手上只有词序列、没有标注——这是互联网的常态。

E 步（期望）：用当前参数，通过前向-后向算法算出每个位置属于每个状态的后验概率，得到期望计数。

例：位置 3 有 0.7 的概率是 NN → 给 C(NN) 加 0.7（计数可以是小数）

M 步（最大化）：用期望计数重新估计 π、A、B。

迭代：E→M→E→… 直到似然收敛。只能保证局部最优，需要多次随机初始化。

一个必须记住的判断

无监督 HMM 确实能「从零学出词性」——学界曾报告它自动把词聚成类似名词/动词的类。但它的准确率显著低于有监督，而且聚类结果与人工标签的对应关系是任意的（需要事后对齐）。所以在有标注数据的今天，它就是思想价值大于实用价值。

为什么必须动态规划

K 个标签、T 个位置 → Kᵀ 条候选路径。K=45、T=20 时约 10³³——枚举绝无可能。

方括号：从上一列所有状态各自乘上转移概率 aᵢⱼ，然后相加——表示“不管从哪来都算上”。

乘 bⱼ(wₜ₊₁)：到了状态 j 之后，还要能“发出”当前这个词。

三段式：初始化 → 逐列递推 → 收尾求和。这是所有 HMM 算法的统一骨架。

Viterbi：与前向只差一个“取最大”环节二 · 知识点讲解 · 考点
每个格子只记两件事

δₜ(j)：到（第 t 个词，状态 j）的最优路径概率。

ψₜ(j)：这条最优路径从上一列的哪个状态过来（回溯指针 / backpointer）。

最后的答案由 δ 给出分数、由 ψ 给出路径——一个数 + 一个指针，就够了。

为什么可以只记最优

最优子结构：如果从起点到 (t, j) 的最优路径经过 (t−1, i)，那么它到 (t−1, i) 的那一段也必然是最优的。

否则可以用更优的那一段替换掉，得到一条更优的整路径——矛盾。

所以每个格子只需保留一个候选，不必保留所有路径。

四步流程（必背） ① 初始化 δ₁(j) = πⱼ · bⱼ(w₁) ψ₁(j) = 0 ② 递推 δₜ₊₁(j) = maxi [ δₜ(i) · aᵢⱼ ] · bⱼ(wₜ₊₁) ψₜ₊₁(j) = argmaxi [ δₜ(i) · aᵢⱼ ] ← 记下赢家 ③ 终止 P* = maxj δ_T(j) ; t*_T = argmaxj δ_T(j) ④ 回溯 t*_{t} = ψ_{t+1}( t*_{t+1} ) ← 从后往前一路查回去 复杂度 O(T · N²)；N=45、T=20 时约 4 万次运算（对比 Kᵀ ≈ 10³³）
一定要分清：δ 是“分数”，ψ 是“父亲的编号”——手算时把两者写在同一格子里，回溯时才不会乱。

HMM 的天花板：三条理论局限 + 一条工程难题环节二 · 知识点讲解
① 观测独立太狠

“在”后面地名高发、首字母大写、词长 2–4 字、词典命中……这些上下文与词形特征塞不进 HMM——塞了就破坏独立假设。

而消歧最需要的恰恰是这些特征。

② 生成式绕路

任务只需要 P(y|x)，HMM 却建模联合 P(x,y)——顺带把“词是怎么生成的”也学了。

数据稀疏时，两头都估不准；而判别式模型可以把全部建模能力放在决策边界上。

③ 只信前一个标签

一阶马尔可夫下，长距离标签依赖丢失。例：句首的 These 决定后面必须是复数名词 NNS，但一阶模型看不到。

缓解手段（高阶 HMM）会让参数从 N² 膨胀到 N³，稀疏问题更严重。

④ 未登录词的工程难题

发射表要枚举词表；测试遇到训练里没见过的词，只能靠平滑（第 7 讲）或后缀启发式（-ed → VBD）。

而这正是第 5 讲词向量与第 8 讲神经方法要解决的问题。

下一步的方向已经很清楚了

要突破这三条，必须做两件事：① 把建模对象从联合分布 P(x,y) 换成条件分布 P(y|x)（判别式）；② 允许使用任意重叠特征（不要求独立）。这正是 MEMM 与 CRF 的设计目标。

MEMM：把转移与发射换成最大熵分类器环节二 · 知识点讲解
定义（McCallum et al., ICML 2000）
P( yₜ | yₜ₋₁ , x ) = (1/Z) · exp( Σₖ λₖ · fₖ( yₜ₋₁ , yₜ , x , t ) ) Z(x, yₜ₋₁) = Σy′ exp( Σₖ λₖ · fₖ( yₜ₋₁ , y′ , x , t ) ) ↑ 只对当前位置归一化（局部归一化）

改造思路：每步一个最大熵分类器（最大熵 = 多分类逻辑回归的学名），直接建模条件概率。

好处：不再管“词怎么生成”；特征随便加——当前词、前后词、大写、后缀、词典命中，HMM 塞不下的全能收进来。

标注偏置（label bias）：局部归一化的代价

机理：局部归一化要求每个状态把手上的概率质量 1 分给所有后继。若某状态在训练数据里只有一个后继，全部质量都流向它——观测被无视。

Lafferty 经典小例（出边数量决定命运）： 状态 1：出边 → 2、→ 3 各 0.5 状态 2：出边 → 4 被迫 = 1.0 → 一旦走进状态 2 这条分支，概率质量“锁死”， 后续观测再不利也无法与其他分支比较

教学例：训练语料里 ORG 都是多词 → 学到 P(I-ORG|B-ORG) ≈ 1.0；测试遇到单 token 机构名“NASA”时，会强行再切出一个词。

一句话总结病理

局部归一化让每个状态“各扫门前雪”：出边少的路径反而占便宜——概率质量不守恒地偏向“选择少”的方向。这不是参数没学好，而是目标函数的形状导致的。

训练时 Z(x) 需要对所有序列求和（用前向-后向算法），复杂度 O(T·K²)，但常数远大于 HMM；训练慢、实现复杂。

2001–2015 年序列标注的标准 SOTA：CoNLL-2003 NER 上 CRF 手工特征系统 F1 约 88–90%，长期是强基线。

今天它仍活跃在解码层——BiLSTM-CRF / BERT-CRF 的最后一层就是它。

2经典方法
