第 9 页：任务定义与结构化预测 环节二 · 知识点讲解 · 考点 输入 x = ( x₁ , x₂ , … , x_T ) 观测序列（词 / 字 / 子词） 输出 y = ( y₁ , y₂ , … , y_T ) 标签序列，|y| = |x| ← 等长约束 目标 ŷ = argmax y ∈ Yᵀ P( y | x ) 整句联合最优，不是逐位最优 理由一：硬约束被无视 # 逐词独立分类（假想）：“贵”被误判为机构开头 郭 贵 冰 入职 华为 B-PER B-ORG I-PER O B-ORG ← 自相矛盾，非法序列 独立分类器 不知道上一步标了什么 ，所以非法序列照样输出。而标签合法性是 确定性规则 ，不是概率偏好。 理由二：标签搭配偏好被浪费 “限定词 → 名词”的概率远高于“限定词 → 动词”；“介词 → 限定词/名词”常见，“介词 → 动词”罕见。 这类 标签之间的转移统计 是极强的信号，但独立分类器用不上——它只看当前词与上下文词，看不到邻居标签。 组合爆炸：不能枚举，但可以动态规划 20 个标签 × 30 个词 = 20³⁰ ≈ 10³⁹ 条候选序列 但标签只在 相邻两列 之间有依赖： → 动态规划 O(T · K²)，K=20、T=30 时约 1.2 万次运算 这就是第 3 讲的动态规划，第三次出场 第 3 讲：编辑距离——在网格里填表求最优编辑路径。 今天： Viterbi ——在同一类网格里填表求最优标签路径。 同样是“填表 + 回溯” ，只是格子里的语义变了。 一句话： 序列标注是结构化预测（structured prediction）在 NLP 里最基础、最典型的形态 。 东北大学软件学院 · 自然语言处理 09

第 13 页：中文标注集：CTB 与《人民日报》体系 环节二 · 知识点讲解 CTB（宾州中文树库） 标签 含义 NN 普通名词 VV 动词 NR 专有名词 VA / VC 形容词性谓词 / 系动词 DEC “的”（补语标记） AS “了”（体标记） 最大特点 ：功能词独立成标签。中文没有屈折形态，虚词承担了语法功能，必须单独标注。 北大《人民日报》体系 / jieba 标签 含义 n 名词 v 动词 nr 人名 ns 地名 nt 机构名 这是中文语料处理最常用的口径之一， jieba.posseg 的输出就是这套标签 ——上机时会见到 nr / ns / nt。 英文类 PTB 标签 中文类 关键差异与示例 名词 NN / NNS / NNP / NNPS 名词 中文 无单复数形态 ，靠“们/几个”表达，故不设复数标签 动词 VB / VBD / VBG / VBN / VBP / VBZ 动词 中文 无屈折 ，时体靠“了/过/着/在”；CTB 再分 VA/VC/VE/VV 工程含义： 跨语言迁移模型时必须先对齐标签集 ，否则“同一个标签名”含义不同，评估结果毫无意义。 东北大学软件学院 · 自然语言处理 13
第 14 页：标注歧义：一个 back 的四种身份 环节二 · 知识点讲解 例句 词性 含义 He came back home. RB 副词 回来 He will back the plan. VB 动词 支持 the back door JJ 形容词 后面的 He hurt his back . NN 名词 背部 ≈ 11.5% Brown 语料中 有多个词性的词型 比例（按 type 统计）。 看起来“大部分词不歧义”。 ≈ 40% 这些歧义词型覆盖的 词例 比例（按 token 统计）。 实际效果：每两个多词就有一个需要消歧。 高频歧义词 that DT / IN / WDT； like VB / IN / JJ； back NN / VB / JJ / RB； up IN / RP / RB。 歧义集中在 高频小词 上——所以封闭类词反而拖累整体准确率。 课堂练习：中文一句话四个“把” “一把 把 把 把 住” → 量词 / 介词 / 名词 / 动词。 人靠语感，机器靠上下文特征与标签搭配。 东北大学软件学院 · 自然语言处理 14

第 27 页：两大假设：算法可行的前提，也是能力的上限 环节二 · 知识点讲解 · 考点 假设 ① 齐次一阶马尔可夫 P( tᵢ | t₁ … tᵢ₋₁ ) ≈ P( tᵢ | tᵢ₋₁ ) 当前标签只看 前一个标签 ——与第 7 讲的 bigram 完全同构，只是建模对象从「词」换成了「标签」。 代价 ：长距离标签依赖丢失。例：These 决定后面必须是复数名词，但一阶模型看不到句首的 These。 缓解 ：高阶 HMM（trigram）。参数从 N² 涨到 N³——45³ ≈ 9.1 万，稀疏更严重。 假设 ② 观测独立 P( wᵢ | x 全部 , y 全部 ) ≈ P( wᵢ | tᵢ ) 当前词只由 当前标签 发射，与前后词、前后标签都无关。 因果方向 ：HMM 认为“标签决定词”——所以要先定标签，再由标签生成词。 代价 ：词与词之间的相互影响被丢掉。而消歧最需要的恰恰是这种影响（“东北大学”后面常跟“软件学院”）。 “假，但有用” 这两个假设在真实语言里显然不成立；但正因为它们成立，HMM 才能把指数级的路径搜索变成 O(T·N²) 的动态规划。 用近似换可计算性——这是统计 NLP 里反复出现的取舍。 必须能背： 一阶马尔可夫（标签只看前一个标签）+ 观测独立（词只由当前标签发射） ——HMM 的强与弱都由这两条决定。 东北大学软件学院 · 自然语言处理 27
第 28 页：参数从哪来：有监督数数，无监督 EM 环节二 · 知识点讲解 有监督：MLE 就是数数（与第 7 讲同构） 转移 aᵢⱼ = C( tᵢ , tⱼ ) / C( tᵢ ) “标签 i 后面接标签 j 的次数 / 标签 i 出现的次数” 发射 bⱼ(w) = C( tⱼ , w ) / C( tⱼ ) “标为 j 的位置上出现词 w 的次数 / 标为 j 的次数” 初始 πᵢ = C( 句首是 tᵢ ) / 句子总数 教学算例 ：C(NN)=1000、C(NN,VB)=120 → P(VB|NN)=0.12；C(VB)=800、C(VB,苹果)=8 → P(苹果|VB)=0.01。 一句话 ：HMM = 标签上的 bigram 语言模型 + 词上的发射表——两样都是第 7 讲学过的计数。 无监督：EM 与 Baum-Welch 手上只有词序列、没有标注——这是互联网的常态。 E 步（期望） ：用当前参数，通过前向-后向算法算出每个位置属于每个状态的 后验概率 ，得到期望计数。 例：位置 3 有 0.7 的概率是 NN → 给 C(NN) 加 0.7 （计数可以是小数） M 步（最大化） ：用期望计数重新估计 π、A、B。 迭代 ：E→M→E→… 直到似然收敛。 只能保证局部最优 ，需要多次随机初始化。 一个必须记住的判断 无监督 HMM 确实能「从零学出词性」——学界曾报告它自动把词聚成类似名词/动词的类。但它的准确率显著低于有监督， 而且聚类结果与人工标签的对应关系是任意的 （需要事后对齐）。所以在有标注数据的今天，它就是思想价值大于实用价值。 东北大学软件学院 · 自然语言处理 28
第 29 页：HMM 三大问题：评估 · 解码 · 学习 环节二 · 知识点讲解 · 考点 问题 输入 → 输出 算法 复杂度 NLP 里的用途 ① 评估 λ, O → P(O | λ) 前向算法 O(n·N²) 模型选择、给候选句打分（语音识别里更核心） ② 解码 λ, O → 最优状态序列 t̂ Viterbi + ψ 回溯 O(n·N²) 本讲主角 ：POS / NER / 分词的推断 ③ 学习 O → 参数 π, A, B 有监督 MLE；无监督 Baum-Welch O(n·N²) / 轮 从标注语料或无标注语料训练模型 前向与 Viterbi 只差一个运算符 前向（评估） Viterbi（解码） 聚合方式 Σ 求和（所有路径） max 取最大（只留最优） 回答的问题 这条观测总共有多可能 哪一条标签链最可能 是否回溯 不需要 需要 ψ 指针表 复杂度 O(n·N²) O(n·N²) 这个“一个运算符之别”极大压缩了要记的公式量。 为什么必须动态规划 K 个标签、T 个位置 → Kᵀ 条候选路径。K=45、T=20 时约 10³³——枚举绝无可能。 最优子结构 ：到某个格子 (t, j) 的最优路径，其前缀也必然是最优的。所以每个格子只需保留一个数（最优值）和一个指针（从哪来）。 于是复杂度从 Kᵀ 降到 O(T·K²) 。 这是 第 3 讲动态规划的第三次出场 ：编辑距离 → 拼写纠错 → Viterbi，骨架都是“填表 + 回溯”。 东北大学软件学院 · 自然语言处理 29
第 30 页：前向算法：指数级路径，多项式合并 环节二 · 知识点讲解 思想：P(O) = Σ 所有路径 y P(O, y) —— Kᵀ 条路径枚举不起 但所有“第 t 个标签是 j”的路径， 前缀可以合并 定义：αₜ(j) = P( w₁ … wₜ , qₜ = sⱼ | λ ) = “以状态 j 结尾、生成前 t 个词”的 所有路径概率之和 三步递推： ① 初始化 α₁(j) = πⱼ · bⱼ(w₁) ② 递推 αₜ₊₁(j) = [ Σᵢ αₜ(i) · aᵢⱼ ] · bⱼ(wₜ₊₁) └─ 从上一列各状态汇聚 ─┘ └─ 吐出当前词 ─┘ ③ 终止 P(O | λ) = Σⱼ α_T(j) 网格直觉 把 T 个位置画成列、K 个标签画成行，构成一个 K×T 的网格；列与列之间全连接。 αₜ(j) = 汇聚到该格子的所有路径概率之和 。每算一个新格子，只需用到上一列的 K 个数——这就是“共享前缀”的威力。 怎么读这个公式 方括号 ：从上一列所有状态各自乘上转移概率 aᵢⱼ，然后 相加 ——表示“不管从哪来都算上”。 乘 bⱼ(wₜ₊₁) ：到了状态 j 之后，还要能“发出”当前这个词。 三段式 ：初始化 → 逐列递推 → 收尾求和。这是所有 HMM 算法的统一骨架。 东北大学软件学院 · 自然语言处理 30

第 32 页：Viterbi：与前向只差一个“取最大” 环节二 · 知识点讲解 · 考点 每个格子只记两件事 δₜ(j) ：到（第 t 个词，状态 j）的 最优 路径概率。 ψₜ(j) ：这条最优路径从上一列的 哪个状态 过来（回溯指针 / backpointer）。 最后的答案由 δ 给出分数、由 ψ 给出路径—— 一个数 + 一个指针，就够了 。 为什么可以只记最优 最优子结构 ：如果从起点到 (t, j) 的最优路径经过 (t−1, i)，那么它到 (t−1, i) 的那一段也必然是最优的。 否则可以用更优的那一段替换掉，得到一条更优的整路径——矛盾。 所以每个格子只需保留一个候选，不必保留所有路径。 四步流程（必背） ① 初始化 δ₁(j) = πⱼ · bⱼ(w₁) ψ₁(j) = 0 ② 递推 δₜ₊₁(j) = max i [ δₜ(i) · aᵢⱼ ] · bⱼ(wₜ₊₁) ψₜ₊₁(j) = argmax i [ δₜ(i) · aᵢⱼ ] ← 记下赢家 ③ 终止 P* = max j δ_T(j) ; t*_T = argmax j δ_T(j) ④ 回溯 t*_{t} = ψ_{t+1}( t*_{t+1} ) ← 从后往前一路查回去 复杂度 O(T · N²)；N=45、T=20 时约 4 万次运算（对比 Kᵀ ≈ 10³³） 一定要分清： δ 是“分数”，ψ 是“父亲的编号” ——手算时把两者写在同一格子里，回溯时才不会乱。 东北大学软件学院 · 自然语言处理 32

第 36 页：15 行 Viterbi：代码与公式的逐行对应 环节二 · 知识点讲解 # 纯 Python，无依赖，直接可跑 def viterbi (obs, states, pi, A, B): delta = {j: pi[j] * B[j][obs[0]] for j in states} # ① 初始化 δ₁ psi = [] # ψ 指针表 # ② 逐列递推 for w in obs[1:]: nd, np_ = {}, {} for j in states: cand = {i: delta[i] * A[i][j] for i in states} i_best = max(cand, key=cand.get) # argmax np_[j] = i_best # 记下赢家 nd[j] = cand[i_best] * B[j][w] # × 发射 psi.append(np_); delta = nd last = max(delta, key=delta.get) # ③ 终止 path = [last] for np_ in reversed(psi): # ④ 回溯 path.append(np_[path[-1]]) return path[::-1], delta[last] 代码与公式的对应关系 代码 公式 delta = {...} δ₁(j) = πⱼ · bⱼ(w₁) cand = {...} δₜ(i) · aᵢⱼ（所有候选） i_best = max(...) ψₜ₊₁(j) = argmaxᵢ nd[j] = ... * B[j][w] δₜ₊₁(j) = max × bⱼ(wₜ₊₁) last = max(delta) P* = maxⱼ δ_T(j) for np_ in reversed(psi) t*_t = ψₜ₊₁(t*ₜ₊₁) 运行结果 ：path = ['N','V','N']，prob = 0.0252 —— 与手算完全一致。 工程实现的两个要点 ① log 空间 ：乘法变加法，避免长序列下溢；max 不变，Σ 换成 logsumexp。 ② 约束转移 ：BIO 非法转移的 log 概率设为 -inf ，最优路径必然合法（第 21 页的做法）。 自学任务会用到 把第 33–35 页的三张表填进这段代码，验证输出与手算一致；再把 max 换成 sum ，就得到前向算法——亲手体会“一个运算符之别”。 东北大学软件学院 · 自然语言处理 36
第 37 页：贪心为什么不行：局部最优 ≠ 全局最优 环节二 · 知识点讲解 经典算例：Time flies like an arrow. 模型（2 状态）： π: N 0.6, V 0.4 A: N→N 0.3, N→V 0.7 ｜ V→N 0.8, V→V 0.2 B: P(time|N)=0.4, P(time|V)=0.6 P(flies|N)=0.3, P(flies|V)=0.7 做法 A：逐词独立取最大发射（贪心） time → V（0.6 > 0.4） flies → V（0.7 > 0.3） 路径 = V V 整句概率 = 0.4 × 0.6 × 0.2 × 0.7 = 0.0336 做法 第 1 列 δ 第 2 列 δ 最优路径 整句概率 结论 A 贪心（逐词最大发射） N 0.24 V 0.24 只看发射，不看转移 V V 0.0336 局部最优，但整句不是最优 B Viterbi（整句最优） N 0.24 V 0.24 N: max(0.24×0.3, 0.24×0.8)×0.3 = 0.0576（ψ=V） V: max(0.24×0.7, 0.24×0.2)×0.7 = 0.1176 （ψ=N） N V 0.1176 是贪心的 3.5 倍 为什么 Viterbi 选 N V 而不是 V V 因为转移概率在起作用： V→V 只有 0.2 ，而 N→V 有 0.7。虽然“flies”作为动词的发射概率更高（0.7 vs 0.3），但从 N 走到 V 的整体代价更小。 整句最优会自动平衡“发射”与“转移”两笔账。 这就是为什么 POS/NER 的推断必须用 Viterbi 而不是逐位 softmax 取最大——第 8 讲的 BiLSTM-CRF 里，CRF 层做的正是这件事。 东北大学软件学院 · 自然语言处理 37
第 38 页：HMM 的天花板：三条理论局限 + 一条工程难题 环节二 · 知识点讲解 ① 观测独立太狠 “在”后面地名高发、首字母大写、词长 2–4 字、词典命中……这些 上下文与词形特征 塞不进 HMM——塞了就破坏独立假设。 而消歧最需要的恰恰是这些特征。 ② 生成式绕路 任务只需要 P(y|x)，HMM 却建模联合 P(x,y)——顺带把“词是怎么生成的”也学了。 数据稀疏时， 两头都估不准 ；而判别式模型可以把全部建模能力放在决策边界上。 ③ 只信前一个标签 一阶马尔可夫下，长距离标签依赖丢失。例：句首的 These 决定后面必须是复数名词 NNS，但一阶模型看不到。 缓解手段（高阶 HMM）会让参数从 N² 膨胀到 N³，稀疏问题更严重。 ④ 未登录词的工程难题 发射表要枚举词表；测试遇到训练里没见过的词，只能靠平滑（第 7 讲）或后缀启发式（-ed → VBD）。 而这正是第 5 讲词向量与第 8 讲神经方法要解决的问题。 下一步的方向已经很清楚了 要突破这三条，必须做两件事： ① 把建模对象从联合分布 P(x,y) 换成条件分布 P(y|x) （判别式）； ② 允许使用任意重叠特征 （不要求独立）。这正是 MEMM 与 CRF 的设计目标。 东北大学软件学院 · 自然语言处理 38
第 39 页：两大门派：生成式 vs 判别式 环节二 · 知识点讲解 维度 生成式 Generative 判别式 Discriminative 建模对象 联合 P(x, y) = P(x|y) · P(y) 条件 P(y | x)，直接对决策建模 类比 先学“怎么画猫画狗”，再分辨 只学“怎么分辨猫狗” 代表模型 HMM、朴素贝叶斯、N-gram 语言模型 逻辑回归、MEMM、CRF、BiLSTM-CRF、BERT 能用什么特征 受限：受独立假设约束，通常只有“当前词 + 当前标签” 任意重叠特征 ：前后词、后缀、大小写、词典、gazetteer、词向量 数据需求 可用无标注数据（EM）；小数据也能估 通常需要标注数据 标注任务表现 约 96% 量级（POS） 约 97%–99%（CRF / 神经方法） 额外能力 能算 P(x)：可做异常检测、候选句打分、置信度校准 只给决策：一般不提供 P(x) 实践结论 在标注任务上， 判别式通常更好 ——它把所有参数预算都花在决策边界上，而不是去解释“词是怎么生成的”。 但不要因此小看生成式 ① 无监督可用，低资源场景仍有一席之地；② 能算 P(x)，语音识别重排、异常检测依然需要它；③ 可解释、可证明，教学与安全性分析价值高。 一句话： 不是“谁更先进”，而是“建模什么、用什么特征、有没有标注” ——这是本讲培养的选型思维。 东北大学软件学院 · 自然语言处理 39
第 40 页：MEMM：把转移与发射换成最大熵分类器 环节二 · 知识点讲解 定义（McCallum et al., ICML 2000） P( yₜ | yₜ₋₁ , x ) = (1/Z) · exp( Σₖ λₖ · fₖ( yₜ₋₁ , yₜ , x , t ) ) Z(x, yₜ₋₁) = Σ y′ exp( Σₖ λₖ · fₖ( yₜ₋₁ , y′ , x , t ) ) ↑ 只对当前位置归一化（局部归一化） 改造思路： 每步一个最大熵分类器 （最大熵 = 多分类逻辑回归的学名），直接建模条件概率。 好处：不再管“词怎么生成”； 特征随便加 ——当前词、前后词、大写、后缀、词典命中，HMM 塞不下的全能收进来。 标注偏置（label bias）：局部归一化的代价 机理 ：局部归一化要求每个状态把手上的概率质量 1 分给所有后继。若某状态在训练数据里只有一个后继， 全部质量都流向它 ——观测被无视。 Lafferty 经典小例（出边数量决定命运）： 状态 1：出边 → 2、→ 3 各 0.5 状态 2：出边 → 4 被迫 = 1.0 → 一旦走进状态 2 这条分支，概率质量“锁死”， 后续观测再不利也无法与其他分支比较 教学例 ：训练语料里 ORG 都是多词 → 学到 P(I-ORG|B-ORG) ≈ 1.0；测试遇到单 token 机构名“NASA”时，会强行再切出一个词。 一句话总结病理 局部归一化让每个状态“各扫门前雪”： 出边少的路径反而占便宜 ——概率质量不守恒地偏向“选择少”的方向。这不是参数没学好，而是 目标函数的形状 导致的。 东北大学软件学院 · 自然语言处理 40
第 41 页：CRF：给整条序列打一个全局分（2001） 环节二 · 知识点讲解 P( y | x ) = exp( score( x , y ) ) / Z( x ) Z( x ) = Σ 所有候选序列 y′ exp( score( x , y′ ) ) ↑ 全局归一化 ：分母走过全部 y′，不再逐位置归一 score( x , y ) = Σₜ [ 转移得分 ( yₜ₋₁ → yₜ ) + 状态得分 ( x , yₜ ) ] └ 可学习的 K×K 转移矩阵 ┘ └ 任意特征打分 ┘ ① 判别式 保留 MEMM 的特征自由：任意上下文、词形、词典、gazetteer 特征全都能用。 不建模 P(x)，全部能力花在 P(y|x) 上。 ② 全局归一化 分母 Z(x) 对所有候选序列求和，每个候选在同一把尺子下比较。 标注偏置从根上消失 ：不会因为“出边少”而占便宜。 ③ 解码仍是 Viterbi HMM: δₜ₊₁(j) = maxᵢ [ δₜ(i) · aᵢⱼ ] · bⱼ(wₜ₊₁) CRF（换成绩效相加）: δₜ₊₁(j) = maxᵢ [ δₜ(i) + S(i, j, t) ] 非法转移 → 分数设 −∞，输出必然合法。 代价要说清 训练时 Z(x) 需要对所有序列求和（用前向-后向算法），复杂度 O(T·K²)，但常数远大于 HMM；训练慢、实现复杂。 历史地位 2001–2015 年序列标注的 标准 SOTA ：CoNLL-2003 NER 上 CRF 手工特征系统 F1 约 88–90%，长期是强基线。 今天它仍活跃在 解码层 ——BiLSTM-CRF / BERT-CRF 的最后一层就是它。 东北大学软件学院 · 自然语言处理 41
第 42 页：BiLSTM-CRF：神经编码 + CRF 解码约束（2015） 环节二 · 知识点讲解 BiLSTM-CRF 模型结构 ① 输入层 词向量（+ 可选字向量） ↓ ② BiLSTM 编码 正向看后文 / 反向看前文 拼接 [→h ; ←h] ↓ ③ 发射分数层 每位置一个分数向量 （实数，非概率） ↓ ④ CRF + Viterbi 转移矩阵 A[K×K] 整句最优解码 ① 嵌入层 第 5 讲的词向量直接复用；中文常加字向量，或把两者拼接。 预训练向量（Word2Vec/GloVe/FastText）在这里第一次真正落地到任务。 ② BiLSTM 层 每位置输出各标签的 发射分数 ——“看全文的局部打分器”。 “苹果”是水果还是公司，由后面的“手机”裁决（第 8 讲的动机在这里兑现）。 ③ CRF 层 可学习的 K×K 转移矩阵：学到 B-PER→I-PER 高分、B-PER→I-LOC 负分。 推断用 Viterbi 取全局最优；整句分数 = Σ 发射分数 + Σ 转移分数。 为什么有效：三句话 ① 看全文 ：BiLSTM 让每个位置的打分看见全句。 ② 管合法 ：CRF 转移矩阵把 BIO 规则焊进解码，非法序列在 Viterbi 里直接出局。 ③ 一起学 ：训练信号从 CRF 传回嵌入层——特征是为“整句最优”而学，不是为“单点正确”而学。 东北大学软件学院 · 自然语言处理 42

第 44 页：中文 NER：按字标，还是按词标？ 环节二 · 知识点讲解 按词标：误差传播 先分词再标注—— 分词错了，实体边界就没了 。 南京市长江大桥 切分 A：南京市 / 长江大桥 长江大桥是桥名 切分 B：南京 / 市长 / 江大桥 完全走偏 → 一旦切错，后面的实体标注全盘皆输 这是第 4 讲“误差传播”的直接体现。 按字标：主流，但丢词信息 避免误差传播，且天然处理未登录词与网络新词；中文常用基准（MSRA、CLUENER）默认就是 字粒度 。 代价 ：“南京”作为 词 的整体含义，单看“南”“京”两字拿不到。 其他特色痛点 ：无大写线索（英文 NNP 是白送的特征）；机构名嵌套地名；简称与全称混用（“北大”/“北京大学”）。 词汇增强的思想一句话： 字粒度决策时，把“当前字能匹配到词典里的哪些词”注入模型 南 → 能匹配：南京、南京市、南京市长江大桥 候选词的存在本身就是强特征 Lattice LSTM（Zhang & Yang, 2018）： 把词典里的词作为额外路径编入 LSTM —— 中文 NER 里程碑 FLAT（2020）： 把词典格“拍平”成 span 序列，用 Transformer 编码 —— 更快更并行 为什么词典仍然有用 神经模型擅长泛化，但对 领域专名 （药品名、金融产品名、机构简称）仍然容易漏。 词典提供的是 高精度的先验 ，与模型的泛化能力互补——这也是“规则 + 模型”混合方案在工业界长期有效的原因。 东北大学软件学院 · 自然语言处理 44
第 45 页：LLM 时代：从“贴标签”变成“直接抽” 环节二 · 知识点讲解 提示词三件套 # ① 任务定义 从句子中抽取人名(PER)、机构(ORG)、地点(LOC)。 # ② 输出契约 只输出 JSON 数组，字段 entity / type， 不要任何解释，不要 markdown 代码块。 # ③ 输入 句子：郭贵冰在东北大学工作，家住沈阳。 模型输出 [ {"entity":"郭贵冰", "type":"PER"}, {"entity":"东北大学", "type":"ORG"}, {"entity":"沈阳", "type":"LOC"} ] 三个变化 ① 任务形式 ：序列标注 → 文本生成。不再需要 BIO 编码，也 天然支持嵌套实体 （BIO 需要多层标注的问题被绕开）。 ② 标注成本 ：标几千句训练 → 写一段提示词 。零样本 / 少样本即可起步（第 14 讲 ICL 系统展开）。 ③ 类型变更 ：改一行提示词 vs 重新标注 + 重新训练。对类型频繁变动的业务价值极大。 四个必须讲透的风险 幻觉 ：抽出原文里根本不存在的实体——必须做“字符串回查原文”校验 边界不精确 ：返回的是字符串，很难精确映射回原文 offset 格式不稳定 ：JSON 括号缺漏、类型名不统一——需要 schema 校验 + 重试 长文本召回下降 ：文档很长时，后半部分实体容易漏——需要分块 + 合并（第 15 讲） 工程上的正确姿势 LLM 预抽 + 规则/小模型复核 ：用 LLM 快速覆盖长尾类型，用确定性规则或小模型保证边界与格式。 评估不能省 ：零样本也要在自建的 50–200 条测试集上算实体级 F1，否则无法判断提示词改动的效果。 东北大学软件学院 · 自然语言处理 45

第 52 页：本讲小结 环节四 · 小结 1 任务与暗线 一词一标签 + 整句联合决策 。形式化是 ŷ = argmax_y P(y|x)，输出等长且有硬约束。 标签依赖（BIO 合法性）是全部模型的立论之本——也是 动态规划第三次出场 的理由：Kᵀ 条路径里找最优。 2 经典方法 HMM ：五元组 π/A/B + 两假设（一阶马尔可夫、观测独立），生成式； Viterbi 用 max + ψ 指针解最优链。 MEMM → CRF ：沿“判别式 + 特征自由 + 全局归一化”修补； 标注偏置 是分水岭。 3 实战与演进 NER = 边界 × 类型全对 ，实体级 F1 一错两罚；不报 token accuracy。 BiLSTM-CRF （看全文 + 管合法 + 一起学）→ BERT （约 93）→ LLM 生成式抽取 （零标注起步、支持嵌套、需约束格式）。 一句话带走 序列标注的整部历史，就是一条 “解开一个约束、性能上一个台阶” 的链条：解开观测独立 → CRF；解开手工特征 → BiLSTM；解开从零训练 → BERT；解开标注依赖 → LLM。你学的不是某个模型，而是这条思路。 复习索引： 公式速查（下一页）· Viterbi 手推与代码 · 实体级 P/R/F1 手算 · HMM 五元组与两假设 · BIO 合法性 · 生成式 vs 判别式 · 五代方法对比表 。 东北大学软件学院 · 自然语言处理 53
第 53 页：公式速查：一张纸复习本讲 环节四 · 小结 · 复习索引 约定：A 是标签→标签，B 是标签→词；前向用 Σ 聚合所有路径，Viterbi 用 max 只留最优路径。 ① HMM 五元组 λ = (N, M, π, A, B) N 状态集合（标签数） M 观测集合（词表） πᵢ = P(q₁ = sᵢ) A aᵢⱼ = P(qₜ₊₁=sⱼ | qₜ=sᵢ) 每行和为 1 B bⱼ(k) = P(v_k | sⱼ) 每行和为 1 ② 两假设与生成式目标 ① 齐次一阶马尔可夫 P(tᵢ|t₁…tᵢ₋₁) ≈ P(tᵢ|tᵢ₋₁) ② 观测独立 P(wᵢ|全部) ≈ P(wᵢ|tᵢ) 生成式目标： t̂ = argmax ∏ᵢ P(wᵢ|tᵢ)·P(tᵢ|tᵢ₋₁) └─ 发射 B ─┘ └─ 转移 A ─┘ ③ 前向 vs Viterbi：只差一个运算符 前向 α₁(j) = πⱼ·bⱼ(w₁) αₜ₊₁(j) = [Σᵢ αₜ(i)·aᵢⱼ]·bⱼ(wₜ₊₁) P(O|λ) = Σⱼ α_T(j) Viterbi δ₁(j) = πⱼ·bⱼ(w₁) δₜ₊₁(j) = maxᵢ[δₜ(i)aᵢⱼ]·bⱼ(wₜ₊₁) ψₜ₊₁(j) = argmaxᵢ[δₜ(i)aᵢⱼ] 回溯 t*_t = ψₜ₊₁(t*ₜ₊₁) ④ BIO / IOBES 编码与合法性 B-X / I-X / O：片段首 / 片段内 / 非实体 IOBES 另加 E-X（结尾）· S-X（单词） 合法性：I-X 前必须是 B-X 或 I-X 相邻同类实体：第二个必须用 B 开头 约束：非法转移在解码时设为 −∞ ⑤ 实体级 P / R / F1（严格匹配） TP 边界+类型全对；FP 多预测/错；FN 漏掉 P = TP/(TP+FP)；R = TP/(TP+FN) F1 = 2TP/(2TP+FP+FN) 边界错 → 一错两罚（FP + FN） 汇报 NER 用实体级 F1，不用 token 准确率 ⑥ 五代方法与易错清单 HMM → MEMM/CRF → BiLSTM-CRF → BERT → LLM（五代） 易错：A 是行和为 1（不是列） B 是 P(词|标签)；先 max 再乘发射 ψ 记“上一列来源”，不是当前状态 训练与测试编码必须一致（BIO/IOBES） 考点：Viterbi 手推 · 实体级 F1 东北大学软件学院 · 自然语言处理 54
