第 6 页：现场实验：输入法在“预测下一个词” 环节一 · 课程导入 课堂实验：输入 「我明天想」 ，然后 只点第一个候选词 ，连续点 10 次。 我明天想 去 → 我明天想去 看 → 我明天想去看 你 → …… 连续点第一个候选的结果（真实体验）： 我明天想去看你了我在家里等你回来的时候一起吃饭吧 观察：每个局部都挺通顺，连起来却整体跑偏。 原因：它每步只盯着“下一个词像不像”，没有全局规划。 每一步在算什么 输入法给出的候选 = 一个条件概率分布 P(下一个词 | 上文) ；按概率从高到低排出来，就是候选列表。 这和我们学的有什么关系 这就是语言模型的定义本身—— 它不是新东西，只是一个新引擎 ：第 7 讲用计数算这个分布，今天用神经网络算。 核心问题： 怎样让“上文”被高效地记下来，并且能被学习？ 东北大学软件学院 · 自然语言处理 06
第 7 页：回收第 7 讲：N-gram 数不出来的三个坑 环节一 · 课程导入 坑 1 没见过 = 0 概率 “软件学院 读”这个组合语料里没出现，N-gram 直接给 0。 平滑（Add-k / KN）只是打补丁—— 借一点概率，不等于真会 。 坑 2 记忆只有 n−1 个词 “小王在巴黎生活了十年，所以他精通 ___” 要答出“法语”，得记得 八个词之前 的“巴黎”。Trigram 只看前 2 个词，看不见。 坑 3 相似上下文不共享 “猫 吃”与“狗 吃”在计数表里是 两个互不相关的格子 。 “猫吃”学到的规律，一点都帮不到“狗吃”——泛化能力为零。 本讲路线 A：向量治稀疏 Bengio 2003：每个词查表变成 d 维稠密向量，相似词住得近 → 相似上下文自动共享统计。 本讲路线 B：状态治窗口 RNN：用一个隐藏状态 hₜ 压缩“读到目前”的全部历史 → 不再有固定窗口。 一个数据点： 1997 年 LSTM 就发表了，却等到 2014 年才爆发 ——它等的不是灵感，是数据与算力。 东北大学软件学院 · 自然语言处理 07

第 9 页：神经语言模型：任务不变，算法换代 环节二 · 知识点讲解 任务定义（与第 7 讲一致） P(w₁…w_T) = ∏ t=1..T P(wₜ | w₁ … wₜ₋₁) 估计条件分布：P(wₜ | w₁ … wₜ₋₁) 语言模型要回答的问题一个字都没变： 给定上文，下一个词的概率分布是什么？ 变的只是“条件概率怎么算” 第 7 讲（计数） P(猫|我 养 了 一只) = Count(我 养 了 一只 猫) / Count(我 养 了 一只) 本讲（网络） h = f(词的向量序列) → P(·|上文) = softmax(g(h)) 1 参数形态 离散计数表 → 连续权重矩阵。 2 词的形式 孤立编号 → 稠密向量，相似词天然接近。 3 零概率 softmax 永远给每个词正概率——零概率灾难消失。 东北大学软件学院 · 自然语言处理 09
第 10 页：核心思想：把历史压成向量，让相似上下文共享统计 环节二 · 知识点讲解 计数：精确匹配的记忆 count(“我 养 了 猫”) / count(“我 养 了”) “我 养 了 狗” → 另一个格子 两行参数之间没有任何共享 没见过 = 0，只能靠平滑借一点 网络：连续函数的泛化 h = f( C(我), C(养), C(了), C(猫) ) C(·)：共享的嵌入表（稠密向量） v(猫) ≈ v(狗) → f 的输出也接近 P(吃 | 我 养 了 狗) > 0 一句话说清“分布式表示”的威力 把每个词放进一个几何空间，把“上文”压成一个点。 语义相近的历史，落在相近的位置 ——于是模型在一处学到的规律，自动迁移到它从未见过的相似句子上。这是统计方法做不到的事。 所以神经 LM 的第一份礼物不是“更强”，而是 “会泛化” 。 东北大学软件学院 · 自然语言处理 10

第 13 页：FFN-LM 公式与参数清单 环节二 · 知识点讲解 cₜ = [ C(wₜ₋ₙ₊₁) ; … ; C(wₜ₋₁) ] ← 拼接，d·(n−1) 维 h = tanh ( W₁ · cₜ + b₁ ) ← 隐层，H 维 y = W₂ · h + b₂ ← logits，|V| 维 P(wₜ | 上文) = softmax (y) = exp(y_w) / Σ v∈V exp(y_v) 训练目标：min L = − Σ t log P(wₜ | wₜ₋ₙ₊₁ … wₜ₋₁) ← 交叉熵（第 6 讲回响） 参数 形状 规模示例（|V|=5 万，d=128，n=4，H=256） 嵌入表 C |V| × d 50,000 × 128 = 6.4 M （词 → 向量） 隐层 W₁ H × d(n−1) 256 × 384 = 0.098 M （输入 → 隐层） 输出层 W₂ |V| × H 50,000 × 256 = 12.8 M （隐层 → 词表） 总计 — 约 19.3 M ，其中输出层占 66%、嵌入表占 33% 记住这个比例： 大词表的输出层永远是参数大户 ——第 45 页有专门的三条对策。 东北大学软件学院 · 自然语言处理 13
第 14 页：例题：手算 P(fox | the quick brown) 环节二 · 知识点讲解 · 考点 玩具设定 词表 V = {fox, dog, cat, car}，d = 2，H = 2，窗口只看前 1 个词。 C(the) = [0.5, −0.5]ᵀ W₁ = I（单位阵），b₁ = 0 W₂ 的四行 = fox [2,1]｜dog [1,1]｜cat [1,0]｜car [0,0]，b₂ = 0 四步流水线 ① c = [0.5, −0.5]ᵀ ② h = tanh(c) = [0.462, −0.462]ᵀ ③ z = W₂h = [2,1]·h = 0.462 dog: 0.0 cat: 0.462 car: 0.0 ④ softmax(z) softmax 现场估算（考点：会算到小数后两位即可） 候选 logit z exp(z) 概率 解读 fox 0.462 1.587 0.36 最像 dog 0.000 1.000 0.23 次之（与 fox 方向相近） cat 0.462 1.587 0.36 与 fox 同分（向量相同） car 0.000 1.000 0.23 即使从未见过，也不是 0 这里唯一的“知识点”： softmax 保证每个候选都有正概率 ，零概率灾难从结构上消失了。 东北大学软件学院 · 自然语言处理 14
第 15 页：突破与局限：为什么还需要 RNN 环节二 · 知识点讲解 三大突破（2003 年的贡献） 泛化 ：测试困惑度明显优于 trigram 基线，与 n-gram 插值后进一步降低 词向量副产品 ：C 自带语义结构，相似词在空间中靠近——第 5 讲 embedding 的先声 免计数 ：模型即参数，不再维护稀疏计数表，也不再需要平滑补丁 三大局限 窗口固定 ：仍只看 n−1 个词，长程依赖看不见 位置各配权重 ：“巴黎”在倒数第 3 位和倒数第 20 位走完全不同的权重列——同一条知识要在每个位置重新学一遍 参数随窗口膨胀 ：W₁ 从 5d×H 涨到 50d×H，看得越远模型越胖、数据越不够 人类是怎么读句子的？ 我们不会每个词都回头重读前 n 个词，而是把 “读到目前的理解” 留在脑子里，读到新词就更新一次。把这个直觉形式化，就是下一节的 RNN。 下一步的目标： 让“窗口”变成“状态” ——参数不随长度增长，知识在所有位置复用。 东北大学软件学院 · 自然语言处理 15

第 19 页：代码：20 行实现一个最小 RNN 环节二 · 知识点讲解 import numpy as np def rnn_step(x, h, W_xh, W_hh, b): """公式直译：hₜ = tanh(Wₓₕxₜ + Wₕₕhₜ₋₁ + b)""" a = W_xh @ x + W_hh @ h + b return np.tanh(a) input_dim, hidden_dim, T = 3, 4, 5 # 小随机初始化（太大的初值会让 tanh 立刻饱和） W_xh = np.random.randn(hidden_dim, input_dim) * 0.01 W_hh = np.random.randn(hidden_dim, hidden_dim) * 0.01 b = np.zeros(hidden_dim) h = np.zeros(hidden_dim) # h₀ = 0 xs = np.random.randn(T, input_dim) # 5 个词向量 for t, x in enumerate(xs): h = rnn_step (x, h, W_xh, W_hh, b) print(f"t={t+1} |h|={np.linalg.norm(h):.4f} h={np.round(h,3)}") 运行结果（示意） t=1 |h|=0.0152 h=[ 0.004 -0.011 0.006 -0.007] t=2 |h|=0.0241 h=[-0.003 -0.019 0.010 0.012] t=3 |h|=0.0310 h=[ 0.007 -0.026 0.011 0.015] t=4 |h|=0.0355 h=[-0.004 -0.031 0.008 0.017] t=5 |h|=0.0398 h=[ 0.009 -0.035 0.006 0.019] 三处要看清： 整个循环体 只有 3 个参数对象 ，与 T 无关 每次迭代都调用 同一个 rnn_step ——参数共享 把隐藏维调到 512，代码一个字都不用改 对照第 7 讲： N-gram 的“模型”是一张表，RNN 的“模型”是一个函数 f 。 东北大学软件学院 · 自然语言处理 19

第 23 页：训练：自监督目标与教师强制 环节二 · 知识点讲解 自监督：标签就是下一个词 语料: 我 爱 吃 苹 果 样本① 上文[我] → 目标[爱] 样本② 上文[我 爱] → 目标[吃] 样本③ 上文[我 爱 吃] → 目标[苹] 样本④ 上文[我 爱 吃 苹] → 目标[果] 零人工标注；一个 A 句 = A 个样本 每个时间步都是一次第 6 讲的 |V| 类分类 总梯度 = 各时间步梯度之和 ——因为所有时间步共享同一组权重。 教师强制（Teacher Forcing） 阶段 第 t 步的输入 后果 训练 真实的上一个词 稳定、好收敛、可并行（时间步的输入都是已知的） 推理 模型自己刚生成的上一个词 一步错 → 步步错，误差滚雪球 这种训练/推理的输入分布不一致，叫 exposure bias（曝光偏差） 。 缓解手段：计划采样（scheduled sampling）、生成时用 beam search 对抗局部错误。 为什么自监督这么重要： 它让“文本本身”变成无穷无尽的标注数据 ——这是预训练时代（第 12 讲）的地基。 东北大学软件学院 · 自然语言处理 23
第 24 页：评估：困惑度（与第 7 讲同一把尺子） 环节二 · 知识点讲解 定义与手算 PPL = exp( −(1/N) · Σₜ log P(wₜ | w<ₜ) ) = ( ∏ₜ P(wₜ | w<ₜ) )^(−1/N) 几何平均概率的倒数 = 平均分支因子 例：N = 5，概率 = [0.2, 0.5, 0.1, 0.4, 0.25] 乘积 = 0.2×0.5×0.1×0.4×0.25 = 0.001 PPL = 0.001^(−1/5) = 10^0.6 ≈ 3.98 读法：模型每一步像在约 4 个词里挑 两条使用纪律 同一词表、同一分词 才能比较：词表 5 万和 1 万的 PPL 不可直接比 内在指标 ≠ 任务表现 ：PPL 低不代表翻译好、分类准，最终要以外在任务为准（第 5 讲评估观） 神经 LM 的历史成绩单 （同语料、同词表）：trigram + KN → 前馈 FFN-LM → RNNLM → LSTM-LM，困惑度一路下降，每一代都是一个台阶。 工程价值：验证集 PPL 是训练中最常用的 早停与选型信号 。 一句话： PPL 只回答“模型对下一个词有多不确定” ，它不回答“模型懂不懂语言”。 东北大学软件学院 · 自然语言处理 24

第 29 页：处方一：梯度裁剪——给梯度装“限高杆” 环节二 · 知识点讲解 按值裁剪（element-wise） g_i ← min( max(g_i, −c), c ) 例：g = [3, 4]，c = 1 → g' = [1, 1] ‖g‖ : 5 → √2 ≈ 1.41 方向 : 53° → 45° ← 被扭了 简单粗暴，会改变梯度方向；个别场景（如 CTC 语音识别实践）仍在用。 按范数裁剪（主流，Pascanu 2013） if ‖g‖ > c: g ← g × ( c / ‖g‖ ) 只缩长度，不改方向——学习信号保住 阈值 c 常用 1 或 5 ；爆炸是偶发尖峰，裁掉尖峰不伤正常训练。 RNN 训练标配 ：loss 曲线一有毛刺，先加裁剪。 # PyTorch 一行搞定（放在 loss.backward() 之后、optimizer.step() 之前） loss.backward() torch.nn.utils. clip_grad_norm_ (model.parameters(), max_norm=5.0) optimizer.step() # 同时监控裁剪前的真实范数，它是训练健康度的体温计 gn = torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0) print(f"grad_norm={gn:.3f}") 边界要说清 裁剪 治爆炸，不治消失 。 梯度已经接近 0 时，把它放大到阈值是错误操作——常见错误是设一个很大的 c 并以为万事大吉。 东北大学软件学院 · 自然语言处理 29
第 30 页：门控之前：工程师的四条绷带 环节二 · 知识点讲解 1 截断 BPTT（TBPTT） 序列切成 τ 步一段，梯度只回传 τ 步 for chunk in chunks(seq, τ): loss = forward(chunk, h) loss.backward() # 只到段首 h = h. detach() # 状态剥离计算图 optimizer.step() 前向仍连续（记忆不断），截断的只是 梯度路径 。τ 常取 20–50。 2 好初始化 标准正态初始化会让连乘迅速爆炸；正交初始化让 Wₕₕ 的谱半径接近 1，连乘衰减慢得多。 另有 IRNN：把循环权重初始化为单位阵，让模型一开始“大概记得住”。 3 归一化 LayerNorm 每步归一化激活分布，抑制尺度漂移，间接稳住梯度（对中小规模 RNN 尤其有效）。 4 学习率与预热 降低学习率、加 warmup，能让训练避开早期的爆炸区。 一句话收口 这四条绷带能让普通 RNN 勉强能训 ，但没有一条能真正解决长程依赖——因为它们都在“绕”病根，而病根是 结构 。真正的答案，是下一页的门控。 东北大学软件学院 · 自然语言处理 30
第 31 页：门控思想：给记忆装上可学习的阀门 环节二 · 知识点讲解 什么是“门” gate = σ ( W·[hₜ₋₁ ; xₜ] + b ) ∈ (0, 1)^h 输出 = gate ⊙ 内容 ⊙ = 逐元素乘 每一维一个开度：0 = 全关，1 = 全开 σ 让开度连续可微 → 可以用梯度学习 为什么不用 0/1 硬开关？因为硬开关不可导，梯度传不过去。 用 sigmoid 把开关“软化” ，是门控能端到端训练的关键。 三个动机场景（都来自原始论文） 场景 需求 门怎么帮 序列开头有校验和，结尾要判断对错 第一个词元必须一直记住 学会 之后不再更新 状态 网页情感分析里的 HTML 标签 无关词元应被忽略 学会 跳过 这些位置的写入 书的章节过渡、股市牛熊切换 旧状态必须清空 学会在需要时 重置 普通 RNN 的病：每步“整体重写” hₜ = tanh(W·[xₜ, hₜ₋₁]) —— 旧记忆被无条件覆盖 ，没有任何“保留/丢弃/写入”的选择权。LSTM 的全部设计，就是把这个“无条件重写”改成“有选择地记账”。 记住这个类比： 普通 RNN 是每步重抄一遍笔记本，LSTM 是记账本——只增改需要动的条目 。 东北大学软件学院 · 自然语言处理 31
第 32 页：LSTM：给记忆修一条“加法传送带” 环节二 · 知识点讲解 LSTM 循环体内部结构（原图·中文） 普通 RNN：每步重写 hₜ = tanh( W·[xₜ, hₜ₋₁] )——记忆被整体覆盖；梯度连乘 diag(tanh′)·Wₕₕᵀ → 消失/爆炸。 LSTM：增量记账 Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ（加法主路）；hₜ = oₜ ⊙ tanh(Cₜ)（对外披露）。梯度回传 ∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)——只乘门值，走得远。 账本 vs 报表 Cₜ 是完整账本 （内部长期记忆，不直接对外）； hₜ 是对外报表 （按需披露一部分）。“记忆 ≠ 输出”是 LSTM 最关键的一点。 乘法让梯度指数衰减； 加法是恒等路径 ——反向传播中只是一个常数 1。这一思想后来被 ResNet 与 Transformer 反复复用。 图片来源：D2L 中文版《动手学深度学习》（d2l.ai，CC BY-SA 4.0）。 东北大学软件学院 · 自然语言处理 32
第 33 页：遗忘门 fₜ：旧账销掉多少 环节二 · LSTM 三门之一 fₜ = σ ( W_f · [ hₜ₋₁ ; xₜ ] + b_f ) ∈ (0, 1)^h Cₜ 的第一项 = fₜ ⊙ Cₜ₋₁ ⊙：逐元素乘（Hadamard 积） [hₜ₋₁ ; xₜ]：旧报表 + 新输入拼接后共同决策 演算：一步遗忘 Cₜ₋₁ = [ 0.9, 0.8, −0.6 ] ← 三条旧记忆 fₜ = [ 0.9, 0.1, 1.0 ] ← 本步算出的保留系数 fₜ ⊙ Cₜ₋₁ = [ 0.9×0.9, 0.1×0.8, 1.0×(−0.6) ] = [ 0.81 , 0.08 , −0.60 ] 逐维解读 第 1 维：0.9 → 0.81， 保留九成 第 2 维：0.8 → 0.08， 几乎清空 第 3 维：−0.6 → −0.60， 原样保留 注意：这是 逐维 的开关，不是整体遗忘或整体记住——记忆的每一维有自己独立的开度。 它在真实语言里干什么 读到新主语时，把旧主语的记忆打折；读到“但是”这类转折词时，把前面的情感极性清掉；读到句号时，清空局部状态准备下一句。 遗忘不是缺陷，是一种主动的注意力分配。 直觉： fₜ 第 j 维 ≈ 1 → 原样保留；≈ 0 → 彻底清除；0.5 → 衰减一半 。 东北大学软件学院 · 自然语言处理 33
第 34 页：输入门 iₜ 与候选 C̃ₜ：写多少 · 写什么 环节二 · LSTM 三门之二 候选记忆 C̃ₜ：写什么（内容） C̃ₜ = tanh ( W_C · [hₜ₋₁ ; xₜ] + b_C ) ∈ (−1, 1)^h 用 tanh 而非 σ：内容要能正能负 +0.8 = 给这一维加分 −0.5 = 给这一维减分 输入门 iₜ：写多少（开度） iₜ = σ ( W_i · [hₜ₋₁ ; xₜ] + b_i ) ∈ (0, 1)^h 实际写入量 = iₜ ⊙ C̃ₜ 不是所有新词都值得记 “的、了、是”这类词往往门开度很小 演算：一步写入 iₜ = [ 1.0, 0.5, 0.0 ] ← 允许写多少 C̃ₜ = [ 0.5, −0.4, 0.9 ] ← 想写什么 iₜ ⊙ C̃ₜ = [ 1.0×0.5, 0.5×(−0.4), 0.0×0.9 ] = [ 0.50 , −0.20 , 0.00 ] 读这个结果 第 1 维：全量写入 0.50。 第 2 维：写了负值 −0.20—— 新信息是把这一维往下压 。 第 3 维：候选值 0.9 很“想说”，但门开度为 0， 一个字都写不进去 。 门是最终的准入控制 ——内容再强，也过不了关上的门。 配对记忆： 遗忘门管“丢多少旧”，输入门管“写多少新”，候选管“新内容是什么” 。 东北大学软件学院 · 自然语言处理 34
第 35 页：汇总：细胞状态完整更新一步 环节二 · LSTM 核心 · 考点 Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ └─ 保留的旧账 ─┘ └─ 写入的新账 ─┘ 维度 Cₜ₋₁ 旧记忆 fₜ 保留系数 保留部分 写入部分 iₜ⊙C̃ₜ Cₜ 新记忆 读法 第 1 维 0.90 0.9 0.81 +0.50 1.31 旧账保留 + 新账叠加，记忆增强 第 2 维 0.80 0.1 0.08 −0.20 −0.12 几乎清零后被负值写入， 符号翻转 第 3 维 −0.60 1.0 −0.60 0.00 −0.60 既不清除也不写入， 纹丝不动 三个维度，三种行为 同一时刻，不同记忆维度可以同时“增强、翻转、冻结”——这就是逐维门控的表达力。 对比普通 RNN：hₜ = tanh(...) 是一次 全局非线性重写 ，做不到这种精细分工。 “可加性”的深层意义 Cₜ 与 Cₜ₋₁ 之间是 加性关系 ，不是乘性关系。加性关系在反向传播中的雅可比接近单位阵——误差可以近乎无损地跨越几十上百步。这一条性质，就是 LSTM 能记住长程信息的数学根源。 考点提示： 给出 Cₜ₋₁、fₜ、iₜ、C̃ₜ 四个小向量，能算出 Cₜ ——这是本章最常考的手算题。 东北大学软件学院 · 自然语言处理 35
第 36 页：输出门 oₜ：记忆 ≠ 输出，按需披露 环节二 · LSTM 三门之三 oₜ = σ ( W_o · [ hₜ₋₁ ; xₜ ] + b_o ) ∈ (0, 1)^h ← 披露开度 hₜ = oₜ ⊙ tanh ( Cₜ ) ← 对外报表 两个易考点 为什么先过 tanh？ Cₜ 可以无界增长（加法通道没有压缩），必须压回 (−1,1) 才能安全地喂给下一层 tanh(Cₜ) 不参与接力 ：传给下一步的是 原始 Cₜ ，不是 tanh(Cₜ)。写作时极易写错 账本 vs 报表（再强调一次） Cₜ（账本） hₜ（报表） 角色 长期记忆 本步工作输出 是否对外 否（只负责传下去） 是（喂给输出层/下一层） 数值范围 无界 有界 (−1,1) 更新方式 加法累积 按需披露 为什么这个分离有价值 “把事实一直存着”和“本步需要什么就披露什么”是两个不同的需求。分开之后，模型可以在某个位置 不输出 但仍保留信息，等几十步后再用——这正是长程依赖得以实现的行为基础。 东北大学软件学院 · 自然语言处理 36
第 37 页：LSTM 一步全景：四个小网络 + 两次乘 + 一次加 环节二 · 知识点讲解 · 考点 五式汇总（LSTM 一层） fₜ = σ( W_f [hₜ₋₁ ; xₜ] + b_f ) 遗忘门：旧账留多少 iₜ = σ( W_i [hₜ₋₁ ; xₜ] + b_i ) 输入门：新账写多少 oₜ = σ( W_o [hₜ₋₁ ; xₜ] + b_o ) 输出门：披露多少 C̃ₜ= tanh( W_C [hₜ₋₁ ; xₜ] + b_C ) 候选：新账是什么 Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ 账本更新（加法） hₜ = oₜ ⊙ tanh( Cₜ ) 对外报表 数据流（一句可背的流程） ① 拼接 [hₜ₋₁ ; xₜ] ② 算三个门 fᵢo（σ）+ 候选 C̃（tanh） ③ 更新账本：Cₜ = f⊙Cₜ₋₁ + i⊙C̃ ④ 生成报表：hₜ = o⊙tanh(Cₜ) 参数账 ：四组 h×(d+h) 矩阵 → 约为同维普通 RNN 的 4 倍 。这是 LSTM 比 RNN 慢的直接原因。 hₜ₋₁, xₜ 输入 → σ 遗忘门 f σ 输入门 i tanh 候选 C̃ σ 输出门 o 四个并行的小网络 → Cₜ = f⊙Cₜ₋₁ + i⊙C̃ 账本（加法主路） → hₜ = o⊙tanh(Cₜ) 报表（对外） 记忆锚点： 三门一候选 → 一次乘一次加 → 一个压缩输出 。合上书，能默画出这一行就掌握了 LSTM。 东北大学软件学院 · 自然语言处理 37
第 38 页：为什么治住了梯度：∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ) 环节二 · 知识点讲解 · 考点 三步推导： ① Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ ② ∂Cₜ/∂Cₜ₋₁ ≈ diag( fₜ ) ← 主项（忽略门的间接依赖） ③ ∂C_t/∂C_k ≈ ∏ i=k+1..t diag( f_i ) ← 只乘门值 对照 RNN：∂hₜ/∂hₜ₋₁ = diag( tanh′ ) · Wₕₕᵀ ← 乘权重矩阵 差别在哪：乘“矩阵” vs 乘“门值” 普通 RNN LSTM 乘什么 权重矩阵 Wₕₕᵀ 门值 fₜ（对角阵） 可控性 由谱半径决定，难控 模型可学会让 f ≈ 1 后果 指数衰减或放大 近乎无损地跨多步 两点必须澄清（防误区） 是“缓解”不是“消灭” ：门值 小于 1 ，步数足够长仍会 ∏f 缓慢衰减；实测 LSTM-LM 的有效依赖约 200 词量级 h 通路仍在 ：从 hₜ 出发的梯度仍要经过输出门与 tanh，输出路径依旧会衰减 一句话总结门控的功劳 普通 RNN 把“能不能记住”交给运气（权重矩阵的谱半径）；LSTM 把它变成 可学习的决策 （门值）。从“碰运气”到“学习怎么记”——这是深度学习里最漂亮的一类设计。 东北大学软件学院 · 自然语言处理 38

第 40 页：GRU（Cho 2014）：两门一态的减法设计 环节二 · 知识点讲解 · 考点 GRU 循环体内部结构（原图·中文） 四行公式 zₜ = σ( W_z xₜ + U_z hₜ₋₁ ) ← 更新门 rₜ = σ( W_r xₜ + U_r hₜ₋₁ ) ← 重置门 h̃ₜ = tanh( W xₜ + U( rₜ ⊙ hₜ₋₁ ) ) ← 候选状态 hₜ = (1−zₜ) ⊙ h̃ₜ + zₜ ⊙ hₜ₋₁ ← 凸组合（Cho 约定） 两个门各管什么 更新门 z ：新旧状态各占几成，z 大保留旧记忆、z 小接纳新候选。 重置门 r ：算候选时带多少旧记忆，r≈0 表示“翻篇了，只看当前输入”。 为什么能省掉一个门 LSTM 的“遗忘/写入”是两个独立旋钮；GRU 把它们 绑成一补一 （1−z 与 z），参数少约 25%，效果相当。 经验规律： 小数据/试错 → GRU；大数据/精度 → LSTM 。 ⚠ 方向约定 ：本页用 Cho 2014 原文约定（(1−z) 配新候选）；cuDNN 等框架写作 hₜ = zₜ⊙h̃ₜ + (1−zₜ)⊙hₜ₋₁， 读代码前先确认 。 图片来源：D2L 中文版《动手学深度学习》（d2l.ai，CC BY-SA 4.0）。 东北大学软件学院 · 自然语言处理 40
第 41 页：GRU 演算：更新门是一个“新旧插值旋钮” 环节二 · 知识点讲解 设定（一维，便于手算） hₜ₋₁ = 0.8 （旧状态） h̃ₜ = −0.4 （本步算出的候选） hₜ = (1−z)h̃ₜ + z·hₜ₋₁ z 取值 计算 hₜ 语义 z = 0.1 0.9 × (−0.4) + 0.1 × 0.8 −0.28 几乎完全接纳新候选（“换挡”） z = 0.5 0.5 × (−0.4) + 0.5 × 0.8 0.20 新旧各占一半（请学生现场算） z = 0.9 0.1 × (−0.4) + 0.9 × 0.8 0.68 几乎完全保留旧状态（“按住”） 对照 LSTM：谁在控制更新幅度 LSTM 用 f 与 i 两个独立旋钮；GRU 只用一个 z，另一个方向由 1−z 自动决定。 所以 GRU 的状态更新是 凸组合 ：hₜ 永远落在 hₜ₋₁ 与 h̃ₜ 之间，不会跑出区间——数值更稳。 重置门 r 的作用（叠加效果） r 只影响候选的算法：h̃ₜ = tanh(Wxₜ + U(r⊙hₜ₋₁))。 r ≈ 0 ：候选几乎只由当前输入决定 → “清空旧账重新想” r ≈ 1 ：带着旧记忆一起算 → “在已有理解上继续推” 一句话： GRU = 用更少的参数，把“记忆保留”和“记忆更新”做成一个旋钮 。 东北大学软件学院 · 自然语言处理 41
第 42 页：LSTM vs GRU：减法减掉了什么 环节二 · 知识点讲解 · 考点 维度 LSTM（1997 / 2000） GRU（Cho 2014） 门数量 3 个：遗忘 f / 输入 i / 输出 o 2 个：更新 z / 重置 r 状态通路 双轨：细胞 C（内部账本）+ 隐状态 h（对外报表） 单轨：只有 h，身兼账本与报表 遗忘与写入 两个 独立可调 的旋钮（f 与 i） 互补绑定 （1−z 与 z） 循环体参数 4 × h(d+h) + 4h 偏置（约为普通 RNN 的 4 倍） 3 × h(d+h) + 3h 偏置（ 省约 25% ） 梯度通路 C 通道：∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)，保护更彻底 h 通道：hₜ 中含 1−z 的直连项，同样有效 计算速度 较慢（矩阵多一组） 较快，收敛常更快 经验建议 数据充足、追求精度上限、需要精细记忆控制 小数据、快速试错、算力受限、序列较长 结论要克制 Chung 等 2014 的实证研究：GRU 在多数任务上与 LSTM 效果相当，收敛更快 ，参数更少。 怎么选 先跑 GRU 作为快速基线；如果长依赖任务（如文档级建模）表现不足，再换 LSTM 调容量。 不要为了“更新”而选型。 东北大学软件学院 · 自然语言处理 42
第 43 页：收口对比：vanilla RNN / LSTM / GRU 环节二 · 知识点讲解 · 考点 维度 vanilla RNN LSTM GRU 循环体参数 h(d+h) + h 4× （四组门矩阵） 3× （省约 25%） 门 无 遗忘 / 输入 / 输出 更新 / 重置 记忆通路 仅 h，每步整体重写 C 加法账本 + h 报表 h 兼任账本与报表 梯度回传 ∏ diag(tanh′)·Wₕₕᵀ ∏ diag(fₜ)（主路） (1−z) 直连项 + 门值连乘 长程依赖 几十步量级 约 200 词量级 与 LSTM 相当 并行性 三者都不可时间并行 ——hₜ 必须等 hₜ₋₁（共同的结构性瓶颈） 典型场景 教学 / 极小任务 / 短序列 大精度、长序列、精细记忆控制 小数据、快速试错、算力受限 一句话：门控没有过时，它只是换了皮 “对信息流做动态的、可学习的开合控制”这一思想，后来出现在： 注意力 （第 10 讲：打分→归一→加权，是对“哪些位置开门、开多大”的软门控）、 残差连接 （第 11 讲：一条默认全开的高速公路）、 SwiGLU （大模型标配激活：内容 × 门）。 所以学 LSTM 不是为了用 LSTM，而是为了 看懂后面所有“门”的祖先 。 东北大学软件学院 · 自然语言处理 43
第 44 页：两个正交扩展：双向与堆叠 环节二 · 知识点讲解 双向 RNN：看得全，但抄不得答案 前向: →hₜ = f( xₜ , →hₜ₋₁ ) t: 1 → T 后向: ←hₜ = f( xₜ , ←hₜ₊₁ ) t: T → 1 表示: hₜ = [ →hₜ ; ←hₜ ] ∈ R^(2h) 为什么需要 ：“苹果”是水果还是公司，要看右边有没有“发布”“手机”；词性标注要看全句。 关键限制 ：双向需要完整输入， 不能用于自回归生成 （生成第 t 个词时不可能知道右边的词）。 两条链的参数是独立的，不是共享的——参数量翻倍。 堆叠 RNN：深度 ≠ 长依赖 第 l 层: h^lₜ = f^l( h^(l−1)ₜ , h^lₜ₋₁ ) 第 1 层的输出序列 → 第 2 层的输入序列 每层参数独立 两个正交的轴 ：层数 L 增加 → 每步表示更抽象；时间 T → 路径长度不变，仍是 O(T)。 经验 ：语音识别常用 5–8 层（低层学音素、高层学语义）；NLP 里 2–4 层常见，再深收益递减。 代价 ：串行计算，层数与时间双重串行，训练慢。 一个必须记住的结论 加层能提升 表示的抽象程度 ，但 不能缩短信息在时间上的路径 。第 1 个词的信息要影响第 100 个词，无论如何都得经过 99 次接力——这是所有循环结构的共同宿命，也是注意力机制要打破的东西。 东北大学软件学院 · 自然语言处理 44
第 45 页：大词表之痛：输出层占走大部分参数 环节二 · 知识点讲解 典型规模下的三笔账（现场可复算） |V| = 50,000，h = 512，单层 LSTM： 输出矩阵 Wₕᵧ 50,000 × 512 = 25.6 M 输入嵌入表 C 50,000 × 512 = 25.6 M 循环体 4 组 4 × 512 × (512+512) ≈ 2.1 M 输出 + 嵌入 = 51.2 M，占总量约 96% 每步都要对 5 万候选做 512 维点积 + 归一化 为什么这是瓶颈 参数账 ：模型容量被“词汇表”而不是“语言能力”吃掉 计算账 ：每个时间步都做一次 |V| 分类，训练极慢 显存账 ：softmax 的中间激活是 batch × T × |V|，长序列直接爆显存 中文词表更大、更稀疏，这个问题尤其严重（第 4 讲子词的动机之一）。 路线 机制 复杂度 / 特点 层次 softmax Morin & Bengio 2005；Mnih & Teh 2012 词表组织成 Huffman 树，预测 = 从根到叶的一串二分类 O(log V)：5 万词约 16 次判断；树固定后灵活性差，长尾词仍深 NCE / 负采样 Mnih & Teh 2012 把 |V| 分类改成“真词 vs k 个噪声词”的二分类 O(k)：k 取 5–20；训练快，但概率不再严格归一化（生成任务需注意） 自适应 softmax Grave 等 2017 按词频把词表分簇，高频词用短码、长尾词用长码 期望复杂度大幅下降；高频词几乎不损精度 这个问题的现代回声： 大模型的词表仍是 5 万–15 万量级 ——只是输出层与嵌入层通过参数共享与并行化被驯服了（第 12、14 讲）。 东北大学软件学院 · 自然语言处理 45
第 46 页：两个必备工程技巧：Dropout 与 Weight Tying 环节二 · 知识点讲解 坑：Dropout 上循环连接 = 给传送带撒沙子 朴素 Dropout（每步独立采样 mask）： t1: █ ░ █ ░ ░ █ t2: ░ █ ░ ░ █ ░ t3: █ ░ ░ █ ░ █ t4: ░ ░ █ ░ ░ █ 噪声沿状态链累积 → 记忆被打断 时间方向加独立 Dropout = 错误示范 解法 1 ：只丢非循环连接（Zaremba 等 2014）——输入→隐层、隐层→输出可以丢，hₜ₋₁→hₜ 不丢 解法 2 ：变分 dropout（Gal & Ghahramani 2016）——同一序列所有时间步 共用同一个 mask ，噪声在时间上一致 Weight Tying：听得懂与说得出，用同一套词汇 C ∈ R^(|V|×h) 词 → 向量（输入查表） Wₕᵧ ∈ R^(|V|×h) 向量 → 词 logits（输出投影） 形状相同、语义同源 → 令 Wₕᵧ = C # PyTorch：把输出层权重绑定到嵌入层 model.decoder.weight = model.encoder.weight 省掉 25.6 M 参数（上一页的账） 通常还 提升效果 ：强迫“理解一个词”和“生成一个词”共用同一表示 今天几乎所有语言模型都这么做（GPT / BERT / LLaMA） 共同主题： 循环网络的工程细节，往往比结构选择更影响成败 。 东北大学软件学院 · 自然语言处理 46

第 48 页：选词是个旋钮：贪心 ↔ 随机（第 14 讲伏笔） 环节二 · 知识点讲解 同一个分布，四种选法 设模型给出的分布： P = [ 好 0.50, 吃 0.30, 睡 0.15, 打 0.05 ] 策略 做法 效果 贪心（argmax） 每步取概率最大的词 稳定、可复现，但容易重复乏味——状态机一旦回到同一状态就走同样的路 随机采样 按概率抽签 多样，但会选出概率 0.05 的“打”等不合理词 top-k 只保留概率最高的 k 个（如 k=2 → 好/吃），重新归一化后抽 过滤长尾噪声，k 越大越自由 top-p（核采样） 取累计概率刚超过 p 的最小集合（如 p=0.8 → 好+吃+睡） 候选集合随分布自适应：模型越确定，候选越少 温度 T z → z/T 后再 softmax T < 1 分布变尖（保守）；T > 1 变平（多样）；T → 0 退化为贪心 本讲只需要记住 “选词方式是一个旋钮”，模型输出的分布不变，是 怎么用这个分布 在变。 第 14 讲会做的事 系统讲解码策略，并用真实 LLM 做对比实测：同一提示词下温度 0 / 0.7 / 1.2 的输出差异、top-p 对幻觉与重复的影响、束搜索适合什么任务。 东北大学软件学院 · 自然语言处理 48
第 49 页：RNN 的三大局限：通往注意力的路标 环节二 · 知识点讲解 1 串行无法并行 hₜ 依赖 hₜ₋₁ → T 步 必须顺序计算 ，GPU 几千核排队做小矩阵乘。 句长 1000 就要老老实实跑 1000 步——长文本时代这是 结构性硬伤 ，不是优化能救的。 2 长程依赖仍吃力 第 1 个词的信息要传到第 100 个词，必须 逐词接力 99 次 。 路上每过一道门都可能衰减——门再多也是小于 1 的数。实测 LSTM 有效记忆约 100–200 步。 3 信息瓶颈 整句被压进 固定维度 的一个向量 h。句子越长，压缩损失越大。 这正是第 10 讲编码器-解码器要打破的瓶颈。 注意力的三味药（第 10、11 讲预告） 池化 ：所有位置一次性矩阵相乘 → 并行，GPU 满载 直连 ：任意两位置直接连线 → 路径长度 O(1)，不再是 O(距离) 动态 ：每个位置自己决定看谁、看多少 → 不再依赖固定状态 代价也要说清 两两交互 ⇒ 计算与显存按 T² 增长；长文本非常昂贵（第 11 讲的长序列变体、第 14 讲的推理优化都在处理这件事）。 没有免费的午餐：RNN 用时间换空间，注意力用空间换时间。 东北大学软件学院 · 自然语言处理 49

第 57 页：本讲小结 环节四 · 小结 1 动机与范式 N-gram 数不动的是三件事： 稀疏 （没见过就是 0）、 无泛化 （相似上下文不共享）、 固定窗口 （看不见远处）。 Bengio 2003 的路子： 稠密向量 + 函数拟合 ——从“查表”到“学函数”。 2 结构与训练 RNN 用 参数共享 换任意长记忆：hₜ = tanh(Wₓₕxₜ + Wₕₕhₜ₋₁ + b)，标签就是下一个词（自监督）。 代价是 BPTT 的 连乘结构 ：梯度消失（沉默）与爆炸（响亮）。裁剪治爆炸， 门控治消失 。 3 边界与去向 LSTM 用 加法主路 + 逐维门控 把记忆变成可学习的决策（∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)），有效记忆约 200 词。 但 串行瓶颈 与 路径 O(距离) 是循环结构的宿命——这就是第 10、11 讲的动机。 一句话带走 你学的不是几个公式，而是一条 “为治病而设计结构” 的工程思路：先诊断（梯度连乘），再设计（加法主路 + 门控），最后把成功的设计思想复用到更大的系统里（注意力、残差、SwiGLU）。 复习索引： 公式速查（下一页）· RNN 前向手推 · BPTT 连乘 · 两种梯度病的症状与处方 · LSTM 三门 · LSTM vs GRU · 四代 LM 对比表 。 东北大学软件学院 · 自然语言处理 58
第 58 页：公式速查：一张纸复习本讲 环节四 · 小结 · 复习索引 使用约定：RNN 状态用 tanh；LSTM 三个门用 σ、候选用 tanh；GRU 采用 Cho 2014 约定 hₜ = (1−zₜ)⊙h̃ₜ + zₜ⊙hₜ₋₁ 。 ① 前向：FFN-LM 与 RNN FFN-LM c = [C(wₜ₋ₙ₊₁); … ; C(wₜ₋₁)] h = tanh(W₁c + b₁) P = softmax(W₂h + b₂) RNN aₜ = Wₓₕxₜ + Wₕₕhₜ₋₁ + bₕ hₜ = tanh(aₜ)，h₀ = 0 pₜ = softmax(Wₕᵧhₜ + bᵧ) 各时间步共享同一组权重 ② BPTT 与两种梯度病 单步 ∂hᵢ/∂hᵢ₋₁ = diag(tanh′)·Wₕₕᵀ 跨 k 步 ∂h_t/∂h_k = ∏[diag(tanh′)·Wₕₕᵀ] （∏ 自 i=k+1 连乘到 t） 判据 λ·tanh′ < 1 → 消失（沉默） λ·tanh′ > 1 → 爆炸（响亮） 处方 爆炸 → 按范数裁剪（max_norm=5） 消失 → 换结构（门控） ③ LSTM 一步（三门一候选） fₜ = σ(W_f [hₜ₋₁;xₜ] + b_f) 遗忘 iₜ = σ(W_i [hₜ₋₁;xₜ] + b_i) 输入 oₜ = σ(W_o [hₜ₋₁;xₜ] + b_o) 输出 C̃ₜ = tanh(W_C [hₜ₋₁;xₜ] + b_C) 候选 Cₜ = fₜ⊙Cₜ₋₁ + iₜ⊙C̃ₜ 账本 hₜ = oₜ⊙tanh(Cₜ) 报表 梯度 ∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ) ④ GRU 一步（两门一态） zₜ = σ(W_z xₜ + U_z hₜ₋₁) 更新门 rₜ = σ(W_r xₜ + U_r hₜ₋₁) 重置门 h̃ₜ = tanh(W xₜ + U(rₜ⊙hₜ₋₁)) 候选 hₜ = (1−zₜ)⊙h̃ₜ + zₜ⊙hₜ₋₁ ⚠ 框架常写 hₜ = zₜ⊙h̃ₜ + (1−zₜ)⊙hₜ₋₁ （cuDNN / PyTorch）声明约定再用 ⑤ 尺寸与参数账（|V|=50k，d=h=512） 输出层 Wₕᵧ |V|×h = 25.6 M 嵌入表 C |V|×h = 25.6 M LSTM 循环体 4·h(d+h) ≈ 2.1 M GRU 循环体 3·h(d+h)（省约 25%） FFN-LM |V|d + H·d(n−1) + |V|H 输出+嵌入 ≈ 51.2 M ≈ 96%（词表之痛） ⑥ 高频易错清单 Cₜ 接力的是 原值 ，不是 tanh(Cₜ) GRU 两套约定，写公式前先声明 output (T,N,H)；h_n/c_n (L,N,H) 双向可标注、不可自回归生成 weight tying：Wₕᵧ = C 比 PPL 用同一词表与同一分词 东北大学软件学院 · 自然语言处理 59
