编码器塔（左）：读懂源句
源 token → Embedding + 位置编码 ↓ ┌──────────────────────────────┐ │ 多头自注意力 → Add & LN │ │ FFN（逐位置）→ Add & LN │ × N = 6 层 └──────────────────────────────┘ ↓ 输出 memory（n × 512）→ 供给解码器

每层 两个子层；输出是“读懂后”的上下文表示，每个位置都融合了全句信息。

解码器塔（右）：生成目标句
目标 token（右移一位）→ Embedding + PE ↓ ┌──────────────────────────────┐ │ ① Masked 多头自注意力 → Add & LN │ │ ② Cross-Attention → Add & LN │ × N = 6 层 │ ③ FFN（逐位置） → Add & LN │ └──────────────────────────────┘ ↓ 线性层 + softmax → 下一个词分布

每层 三个子层（比编码器多一个 cross-attention）；自注意力带掩码，不许偷看未来。

两塔的唯一区别

结构对称、层数相同、超参数相同。差别只有两处：① 解码器的自注意力带 causal mask；② 解码器多一个 cross-attention 子层（Q 来自解码器，K/V 来自编码器）。记住这两点，Figure 1 就能默画出来。

编码器层解剖：两个子层与统一的包装环节二 · 知识点讲解 · 考点
子层包装公式（论文原版 Post-LN） SublayerOut = LayerNorm( x + Sublayer( x ) ) └────────── 残差 ──────────┘ 子层 ① Sublayer = MultiHeadSelfAttention( x ) ← 全句互相看 子层 ② Sublayer = FFN( x ) ← 逐位置，不跨位置
残差要求维度一致

x + Sublayer(x) 要能相加，所以每个子层的输入输出维度必须相同。

于是全模型贯穿一个 d_model：base 是 512，big 是 1024。

编码器的工作是“读懂”

自注意力让每个位置看到全句所有位置（双向），FFN 对每个位置做非线性变换。

输出 memory 的每个向量都是“带着全句上下文的词表示”——这就是第 12 讲 BERT 的雏形。

为什么这个包装关键

没有残差：12 层深网络的梯度会衰减到无法训练；没有 LayerNorm：每层输入分布漂移，训练极不稳定。

残差给通路，LN 给稳定——两者合起来让深层 Transformer 成为可能。

默画要点：两个子层 + 两次 Add & LN + 每层一个残差捷径。考试常要求“写出子层包装公式并说明残差与 LN 各自的作用”。

解码器层解剖：三个子层与掩码环节二 · 知识点讲解 · 考点
顺序子层Q / K / V 从哪来职责
①Masked 多头自注意力Q = K = V = 解码器上一子层（同源）基于已生成的内容续写；位置 i 只能看 ≤ i，不许偷看未来
②Cross-Attention（编码器-解码器注意力）Q = 解码器上一子层；K / V = 编码器输出 memory生成时“回看源句”——这是两塔之间唯一的桥
③FFN逐位置，不跨位置与编码器同构，做非线性特征变换
顺序为什么不能乱

先看自己（已生成的目标序列）→ 再看源句（确定该翻译哪部分）→ 最后变换（生成表示）。

如果先做 cross-attention 再做自注意力，当前生成的内容就无法参与对源句的查询——逻辑颠倒。

三个易错点
  • cross-attention 里的 Q 来自解码器，K/V 来自编码器——写反了就完全错了
  • masked 自注意力只在训练时需要掩码；推理时逐词生成，天然看不到未来
  • 每个子层都要有自己的 Add & LN，不是三个子层共用一个
推理时的完整流程：已生成词 → ①masked 自注意力 → ②查源句 → ③FFN → 线性层 → 下一个词分布，循环直到 EOS（第 10 讲的自回归）。

输入表示：词嵌入 + 位置编码环节二 · 知识点讲解
输入向量（每个位置一个 d_model 维向量） 输入i = Embedding( tokeni ) × √d_model + PE( posi ) └────── 语义向量（可学习）──────┘ └─ 位置向量（论文里是固定函数）─┘ d_model = 512；pos = 0, 1, 2, …（位置下标）
① 词嵌入从哪来

子词切分（第 4 讲 BPE/WordPiece）→ 查表得到可学习向量（第 5 讲词向量思想的“静态版”，但这里是从零和模型一起训练）。

词表大小约 3–5 万，嵌入表 |V| × d_model。

② 为什么要乘 √d_model

位置编码的数值在 [−1, 1] 附近；而 d 维随机向量的范数约 √d（方差为 1 时）。

若直接相加，位置信号相对太小、容易被淹没。乘 √d_model 让两者量级相当——这是一处典型的工程细节。

③ 为什么相加而不是拼接

拼接会让维度翻倍（512 → 1024），参数量与计算量都增加；相加在经济性上更好。

论文的消融显示两者效果相当，于是选择了更经济的相加。

一句提醒：token 嵌入是“这个词是什么”，位置编码是“它在第几个位置”——两者相加构成完整的输入表示。

为什么必须有位置编码：置换等变环节二 · 知识点讲解 · 考点
自注意力是“位置盲”的
猫 追 鱼 → 输出 A B C 鱼 追 猫 → 输出 C B A ← 只是换序！ Attention(Q,K,V) = softmax( QKᵀ / √d_k ) V 公式里没有任何一项用到绝对位置 → 打乱输入行序，输出跟着打乱（置换等变）

但「猫追鱼」与「鱼追猫」语义完全不同——语序就是语义，必须显式注入位置。

三种位置信息来源的对比
模型位置信息从哪来
RNN隐含在计算顺序里——第 t 步自然对应第 t 个词
CNN隐含在卷积核的位置里——滑窗天然区分前后
Transformer计算本身与顺序无关 → 必须显式注入位置编码

这是并行化换来的代价：用一次矩阵乘取代 n 次串行计算，就必须额外告诉模型“谁在前、谁在后”。

课堂验证（1 分钟）

把 Q、K、V 的三行同时交换（1↔3），你会看到 S 与 P 的对应行列也交换，最终输出仍然是 V 的加权混合、只是换了个顺序。“位置盲”是可以通过动手验证的数学事实，不是比喻。

自注意力直觉：每个位置都在做一次“软检索”环节二 · 知识点讲解 · 考点
Q · Query 查询

“我想找什么”——每个 token 向全句发出的查询向量。

例：生成/理解“鱼”时，它可能想找“谁在追我”。

来自输入与 WQ 的线性投影。

K · Key 键

“我是什么”——用来被别人的 query 匹配的向量。

例：“追”这个位置的 key 会与“鱼”的 query 高度匹配。

来自输入与 WK 的线性投影。

V · Value 值

“匹配上之后给什么”——真正被加权取走的信息。

例：匹配到“追”之后，把“追赶”这个语义内容按权重取回来。

来自输入与 WV 的线性投影。

与第 10 讲注意力的唯一区别

第 10 讲的注意力是 Q 来自解码器、K/V 来自编码器（跨序列对齐）；自注意力是 Q、K、V 全部来自同一个序列——“self”这个词就是这个意思：每个位置查整个句子，包括它自己。

检索三步（与第 10 讲完全同构）：① query 与每个 key 算相似度 → ② softmax 归一化成权重 → ③ 按权重加权取 value。

Q/K/V 从哪来：三个线性投影环节二 · 知识点讲解 · 考点
输入矩阵：X ∈ Rn × d_model ← n 个 token 的向量堆叠 Q = X · WQ WQ ∈ Rd_model × d_k K = X · WK WK ∈ Rd_model × d_k V = X · WV WV ∈ Rd_model × d_v base 配置： d_model = 512， d_k = d_v = 64
① 三个视角，同一份输入

Q/K/V 都不是输入本身，而是同一输入在三个不同投影下的三个视角。

这样模型才能分别学习“我想找什么”“我是什么”“我能给什么”——如果直接用 X 当三者，灵活性会大幅下降。

② 投影是共享参数

WQ、WK、WV 是可学习参数，在所有位置共享（与 RNN 的参数共享同理）。

参数量各为 d_model × d_k = 512 × 64 = 32,768；三个加起来不到 10 万。

两个易错点
  • 以为 Q/K/V 是三个不同的输入——不是，它们来自同一个 X
  • 以为 d_k 必须等于 d_model——不是，d_k 由头数决定（512/8 = 64）
一句话：自注意力的“学习能力”几乎全部来自这三组投影矩阵——它们决定了每个位置如何提问、如何被匹配、以及给出什么内容。

核心公式：缩放点积注意力四步拆解环节二 · 知识点讲解 · 考点
Attention( Q , K , V ) = softmax( Q Kᵀ / √d_k ) · V
步骤运算含义形状（n 个 token）
①打分 S = Q Kᵀ第 i 个 query 与第 j 个 key 的点积——方向越近分越高（第 5 讲相似度）n × n
②缩放 S / √d_k稳住分布、防止 softmax 饱和，下一页给方差推导n × n
③归一化 P = softmax(·)按行 softmax——每一行和为 1，是各个 key 的注意力分配比例n × n
④加权 O = P · V每个输出是 V 的凸组合（加权平均）——不会凭空造出新方向n × d_v
① softmax 是按行做的

每一行的分母只属于这一行——即“第 i 个位置如何把注意力分配给所有 j”。

做成按列是最常见的实现错误，会让每个位置看到的信息失去归一化。

② n × n 就是 n² 的来源

QKᵀ 要算出 每一对位置的相似度，所以打分矩阵是 n×n。

序列长度翻倍，这个矩阵的规模翻 4 倍——这是第 39 页显存账本的根源。

③ 输出是 V 的凸组合

每一行权重非负且和为 1，所以输出永远落在 value 向量张成的凸包内。

“注意力不会凭空造出新方向”——这条性质在分析模型表达力时非常有用。

不缩放会怎样：softmax 饱和

分数一大，softmax 就变成近似 one-hot：最大项接近 1，其余接近 0。

此时 softmax 的雅可比接近 0 —— 梯度趋近于 0，模型学不动。这就是“饱和”。

数值上还容易溢出（exp(大数) 直接变 inf），需要额外的数值稳定技巧。

三个必须澄清的说法
  • 不是为了“变快”：除以 √d_k 增加了一次缩放运算，代价是正的
  • 不是为了“变成概率”：归一化是 softmax 干的，跟缩放无关
  • 是为了稳住梯度：让 softmax 工作在线性区，梯度能传下去

消融实验：去掉缩放，base 模型在英德上的 BLEU 明显下降——这是论文里被实测验证过的细节。

答题模板：“点积方差为 d_k → 标准差 √d_k → 分数过大使 softmax 饱和、梯度趋近 0 → 除以 √d_k 把方差拉回 1”。

一个必须点明的因果链

并行 → 同样时间能训练更大的模型 → 模型更大需要更多数据 → 数据更多又需要更大模型……大模型的规模军备竞赛，在工程上是被“可并行”这一条性质打开的。而没有并行，再多的算力也换不来更大的模型。

代价也要说清：用 n² 的计算与显存，换来了 O(1) 的串行深度——这笔交易在 2017 年之后被证明极其划算。

多头注意力：定义与公式环节二 · 知识点讲解 · 考点
MultiHead( Q , K , V ) = Concat( head₁ , … , headh ) · WO headi = Attention( Q · WiQ , K · WiK , V · WiV ) base 配置：h = 8 WiQ ∈ R512 × 64 WiK ∈ R512 × 64 WiV ∈ R512 × 64 WO ∈ R512 × 512
① 切分子空间

把 512 维切成 8 个 64 维子空间，每个头在各自的子空间里独立做一次完整的注意力。

所以“多头”不是复制 8 次，而是把表示空间分成 8 份。

② 拼接再融合

8 个头的输出（各 n×64）拼接成 n×512，再过一次线性层 WO 融合。

这一步很关键：它让不同头的信息发生交叉组合，而不是简单并列。

③ 参数量几乎不变

8 个 512×64 的投影拼起来，参数量等于一个 512×512 的投影。

多头不是“8 个独立模型”——它们共享同一份输入与同一份位置信息，只是看不同的子空间。

一句话：把一个大注意力拆成 h 个小注意力，让不同的头去学不同的关系模式，最后再融合。

每个头独立执行“打分 → 缩放 → 行 softmax → 加权”，得到 8 个不同的注意力分布。

8 个头可以完全并行——这是多头在实践中几乎不增加时间开销的原因。

8 个 n×64 拼接成 n×512，再经 W^O 融合成 n×512。

实现提示：不必真的写 8 次循环——把 512 维 reshape 成 8×64，用一次批量矩阵乘完成（PyTorch 的 nn.MultiheadAttention 就是这么做的）。

工程视角：多头是“参数不变、并行度不变，但表达能力变强”的改进——这也是它几乎零成本被所有模型采纳的原因。

为什么多头：让每种关系有专属通道环节二 · 知识点讲解 · 考点
理论：单头是“竞争性”的

一个 softmax 的权重和必须为 1——关注了句法就难同时关注指代。

例如分析“他把书放在桌子上，因为它太重了”：“它”既要对齐“书”（指代），又要与“太重”建立主谓关系。单个注意力分布要同时装下这两种关系，必然互相挤压。

切成 h 个子空间后，每个头独立学一种模式，互不抢权重；低维（64）还起到正则作用。

实证：BERT 的头确实有分工

Clark 等 2019 对 BERT 的注意力头做了系统分析，发现存在功能明确的“专家头”：

头的类型行为模式
位置头专盯前一个词或下一个词——负责局部顺序
句法头对齐句法依存关系（动词↔宾语、名词↔修饰语）
低频词头专门关注罕见词或特殊符号，如 [SEP]、句末标点

把某些头单独剪掉，模型在特定任务上的表现会明显下降——这从反面说明了分工是真实的。

一句话总结

多头不是为了“更大”，而是为了表达更多种关系：一个头只能给出一种注意力分布，而语言里的关系（顺序、句法、指代、共指、语篇）远不止一种。把表示空间分成若干子空间，各自负责一类关系——这是多头最本质的动机。

正弦编码的三个直觉，与可学习方案环节二 · 知识点讲解
1频率阶梯

256 对维度 = 256 个不同频率：最快波长 2π（分辨相邻位置），最慢 10000·2π（编码远距离）。

像二进制计数器：低位每步翻转、高位很久才动——组合起来唯一表示每个位置。

这让每个位置有一个“指纹”，且不同位置的指纹不会重复。

2相对位置可线性表示

三角恒等式保证：对任意固定偏移 k，PE(pos+k) 可以写成 PE(pos) 的线性变换（旋转矩阵）。

于是模型很容易学到“相隔 3 个词”这类相对距离的规律，而不需要为每个绝对位置单独学习。

这条性质是后来 RoPE 旋转位置编码的直接思想源头。

3可学习位置嵌入

另一条路：把 PE 做成 n_max × d_model 的参数表（如 512×512），随机初始化，与词嵌入一起端到端学。

论文选正弦，看重的是外推性。实践提示：可学习表无法处理超出 n_max 的位置。

一句工程判断

正弦与可学习在原始规模下效果相当，说明“位置信息必须注入”这一点是本质的，而“用什么方式注入”在中等长度下并不敏感。但当上下文长度成为竞争焦点（几万到几十万 token）时，编码方式就开始决定成败——这就是后面 RoPE、ALiBi 等方案层出不穷的原因。

∂out / ∂x = I + ∂Sublayer / ∂x └─ 单位阵：不经衰减的直达通路 ─┘

梯度可以沿单位阵 I 无损地回传到很浅的层，不会像纯堆叠那样指数衰减。

这与第 8 讲 LSTM 的加法主路（∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)）是同一个思想：用加性通路对抗乘性衰减。

深度账（现场算一遍）

编码器 = 6 层 × 2 子层 = 12 个子层；解码器 = 6 层 × 3 子层 = 18 个子层；合计 30 个子层。若把残差拆开，相当于一个 30 层以上的深网络——没有残差，这样的深度几乎不可能稳定训练。而今天的 GPT 系模型动辄几十上百层，靠的正是这条通路。

LayerNorm：给每层的分布“校准”环节二 · 知识点讲解 · 考点

  • 为什么用 LN 而不是 BN？序列长度可变、batch 内样本差异大；LN 逐样本统计，不依赖 batch，训练与推理行为一致
  • γ、β 为什么必需？纯归一化会把表示限制在零均值单位方差，丢失尺度信息；可学习的 γ、β 让模型自己决定要多少归一化
  • 放在哪？Post-LN（论文原版）放在子层之后；Pre-LN（现代实现）放在子层之前——下一页专门讲这个差别

Post-LN vs Pre-LN vs RMSNorm环节二 · 知识点讲解 · 考点
Post-LN（论文原版 2017）
out = LN( x + Sublayer( x ) ) └─ 归一化放在残差块之后 ─┘

Xiong 等 2020 用平均场理论证明：初始化时，接近输出层的参数梯度期望偏大，越深越严重。

后果：必须使用精细的学习率 warmup（原论文用了 4000 步），否则训练发散。这既拖慢优化，又增加调参负担。

Pre-LN（现代实现主流）
out = x + Sublayer( LN( x ) ) └─ 归一化放在子层之前 ─┘

优势：梯度尺度更稳定，可以去掉 warmup 或大幅缩短，训练更易收敛，对超参数更宽容。

代价：在极深的网络里最终效果略逊于调好的 Post-LN——但可以通过加层数弥补。

现状：今天绝大多数大模型用 Pre-LN。

RMSNorm：LayerNorm 的瘦身版
LN( x ) = γ ⊙ ( x − μ ) / √(σ² + ε) + β RMSNorm( x ) = γ ⊙ x / RMS( x ) RMS( x ) = √( (1/d) Σi xᵢ² )

去掉 re-centering（不减均值），只保留 re-scaling；也去掉了 β。消融发现 re-scaling 才是收益的主要来源，因此 RMSNorm 更省算力、效果相当。

今天被 Llama、Qwen、GLM 等主流开源模型采用。

一个值得记住的规律

从 Post-LN 到 Pre-LN，从 LayerNorm 到 RMSNorm，都是同一件事：把“能不能训起来”的负担从“精细调参”转移到“结构设计”上。这也是深度学习工程的一个普遍趋势——让默认配置就能工作。

FFN：逐位置的两层 MLP环节二 · 知识点讲解 · 考点
FFN( x ) = max( 0 , x W₁ + b₁ ) W₂ + b₂ └── ReLU ──┘ W₁ ∈ R512 × 2048 ← 升维 4 倍 W₂ ∈ R2048 × 512 ← 降回原维度 论文注：等价于两个核宽为 1 的卷积（即逐位置、不跨位置）
① 逐位置

每个位置独立做同一个 MLP，不跨位置交互。

所以 FFN 不负责“信息搬运”——那是注意力的工作；它负责在每个位置上加工特征。

② 中间升维 4 倍

512 → 2048 → 512：先升维再做非线性，再降回来。

这是经典的“瓶颈式”设计——给非线性变换留出足够空间。4 倍是论文选定的比例，后来大模型多用 8/3 或 4 倍左右。

③ 参数共享

所有位置共享同一套 W₁、W₂——与注意力一样是参数共享。

激活函数从 ReLU 演进到 GELU、SwiGLU（第 6 讲与后续章节会提到），但结构不变。

分工一句话

注意力负责“在不同位置之间搬运信息”，FFN 负责“在每个位置上加工信息”。两者交替堆叠，构成了 Transformer 层的基本节奏：混合 → 加工 → 混合 → 加工……

FFN 参数占比：被低估的大户环节二 · 知识点讲解 · 考点

共同点

三者的计算公式完全相同：softmax(QKᵀ/√d_k)·V，四步流程一模一样。

差别只有两处：Q/K/V 从哪来，以及可见范围（有没有 mask）。

为什么理解可以双向、生成必须单向

理解（分类、标注、抽取）时整句都已知，双向能获得更完整的上下文——这是 BERT 的基础。

生成时第 t 个词的预测不能看到 t 之后的内容，否则就是“抄答案”——这是 GPT 的基础。

这张表通向三种范式

只用① → 编码器-only（BERT）；只用② → 解码器-only（GPT）；①+②+③ → 编码器-解码器（原始 Transformer、T5）。三种范式在本质上的差别就是这张表的组合方式。

易错点 ① 作用位置

mask 必须加在 softmax 之前的分数上。如果作用在 softmax 之后的输出上，归一化已经包含了被禁止的位置，权重不再是合法的概率分布。

易错点 ② 什么时候需要

推理时逐词生成，天然看不到未来——不需要 mask。只有训练时整句并行计算，才必须加 mask 防止“抄答案”。

易错点 ③ padding 也要屏蔽

一个 batch 里不同样本长度不同，需要 padding。PAD 位置也必须屏蔽，否则它们会分走注意力权重，损害真实内容的对齐。

Cross-Attention：两塔之间唯一的桥环节二 · 知识点讲解 · 考点
接线方式（唯一要点）
Q ← 解码器上一子层的输出 “我要生成什么” K , V ← 编码器输出 memory “源句有什么” score = Q Kᵀ / √d_k → softmax → 加权 V

例：编码器读入「猫 追 鱼」，解码器生成到 “tail” 时，query 与三个 key 匹配，“鱼”的分数最高，于是这一步的输出主要由“鱼”的 value 主导——模型因此写出了“尾巴”。

权重就是一张软对齐矩阵

cross-attention 的注意力权重天然是一个目标位置 × 源位置的矩阵——正是第 10 讲那张对齐热图。

无需任何对齐标注，对齐在训练中自动涌现。这是『jointly learning to align』在 Transformer 里的延续。

工程价值：翻译系统可以直接输出这张矩阵做漏译排查与术语一致性检查。

① 唯一的桥

删掉 cross-attention，解码器就完全看不到源句——它会变成一个纯语言模型，只会续写不会翻译。

② 不加 causal mask

源句是全部已知的，所以 cross-attention 不需要 causal mask，每个目标位置都能看到完整源句。

但仍需屏蔽源句的 padding 位置。

③ 与自注意力的区别

自注意力是『自己看自己』（Q/K/V 同源）；cross-attention 是『解码器看编码器』（Q 与 K/V 异源）。

公式一样，接线不同——这也是为什么理解『Q/K/V 从哪来』比记公式更重要。

呼应第 10 讲：cross-attention 就是 Bahdanau 注意力的 Transformer 版本——只不过主干从 RNN 换成了自注意力。

破解 n²：少算 vs 算得聪明（概念）环节二 · 知识点讲解
路线一：少算（算法近似）

不是每对 token 都需要交互——只算一部分：

  • 稀疏化：跨步 / 滑窗 / 全局 token 模式，把 O(n²) 降到 O(n√n) 或 O(n)。代表：Sparse Transformer（Child 2019）、Longformer、BigBird
  • 循环缓存：缓存前段隐状态供后段使用，训短推长。代表：Transformer-XL（Dai 2019）
  • 代价：牺牲一部分“任意两位置直连”的表达能力，可能损失质量
路线二：算得聪明（IO 优化）

不改数学，只改显存读写方式：

  • FlashAttention（Dao 等 2022）：用分块（tiling）把计算留在 GPU 片上 SRAM，大幅减少与 HBM 之间的读写
  • 它是精确注意力——结果与标准注意力数学等价，不牺牲质量
  • 论文的核心洞察：注意力算法应该是“IO 感知”的——理论 FLOPs 不是瓶颈，显存读写才是
  • 代价：需要专门的 CUDA 实现，不像改一行代码那么简单
两条路线的思维差别

路线一问：能不能不算那么多？（改算法，牺牲表达）　路线二问：能不能算得更省？（不改算法，改内存访问）

在真实硬件上，第二类工作常常更划算——因为大部分性能瓶颈根本不在算术，而在数据搬运。这是一个非常值得工程方向学生记住的判断。

理解任务不给双向，是浪费信息；生成任务给双向，就是抄答案。同一套公式，靠一张掩码矩阵区分出两种完全不同的使用方式——这是 Transformer 设计中最优雅的一处。

四支柱 + 一地基
  • 柱 1 自注意力：任意两位置一跳直达，路径 O(1)、训练全并行——治 RNN 两条硬伤的主武器
  • 柱 2 多头：h 个低维子空间并行学不同关系；消融显示单头掉 0.9 BLEU
  • 柱 3 位置编码：给“位置盲”的注意力装序号；正弦 → 可学习 → 相对 → RoPE
  • 柱 4 残差 + LayerNorm：30 个子层能稳定深堆（残差给通路、LN 给稳定）
  • 地基 FFN：逐位置加工信息，占每层参数约 2/3——被低估的大户
为什么取代 RNN：三条根因

① 训练可并行（工程根因）
串行操作 O(1)：整句一次矩阵乘算完，GPU 利用率碾压 RNN——同样时间能训大得多的模型。

② 长程依赖根治（建模根因）
最大路径 O(1)：信息一跳直达、梯度不随距离衰减——LSTM 只能缓解的问题被结构性解决。

③ 可解释可分析（科研根因）
注意力权重是可读矩阵，可以画热图、分析头分工——这让研究迭代速度大幅加快。

代价也要记住

显存与计算按 n² 增长；长上下文昂贵；需要位置编码补语序；注意力权重不等于严格解释。没有免费的午餐——Transformer 用平方级的资源消耗，买来了可并行与短路径。

本讲小结环节四 · 小结
1核心运算

Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V；四步：投影 → 打分并缩放 → 行 softmax → 加权 V。

√d_k 防饱和稳梯度；多头是分空间，不是分模型（参数量几乎不变，表达力更强）。

三种注意力公式相同，区别只在 Q/K/V 从哪来 + 可见范围。

2架构组件

双塔各 6 层：编码器 2 子层、解码器 3 子层（多 cross-attention）。base 配方 512 / 8 / 64 / 2048。

位置编码解决置换等变；残差给通路、LayerNorm 给稳定；FFN 逐位置加工，占每层参数约 2/3。

causal mask 必须加在 softmax 之前。

3为什么赢

串行 O(1) → 训练可并行（工程根因）；路径 O(1) → 长程依赖根治（建模根因）；注意力矩阵可分析 → 研究迭代快（科研根因）。

代价：显存与计算按 n² 增长，长上下文昂贵。
