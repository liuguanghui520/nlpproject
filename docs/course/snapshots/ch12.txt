第 10 页：迁移学习与自监督：免费的监督信号 环节二 · 知识点讲解 · 考点 前提一：参数可迁移 语言任务共享大量 底层规律 ：词形、搭配、句法、语义、常识。这些规律都存在于网络参数里。 所以在一个任务上学到的表示，可以帮助另一个任务——这就是 迁移学习 。 与静态词向量的区别：迁移的不再只是词向量，而是 整个编码器的参数 （含上下文建模能力）。 前提二：标签可自动生成（自监督） 给定无标注序列 x = ( x₁ , x₂ , … , x_T ) 用规则造样本： ( 输入 x′ , 标签 y ) = ( g(x) , f(x) ) g、f 都是规则，无需人工标注 目标 g(x)：输入 f(x)：标签 自回归 去掉最后一位 最后一位的词 MLM 随机挖空 15% 被挖掉的词 为什么这件事如此重要 人工标注的语料最多到百万级，而互联网文本是 万亿 token 级 ——差六个数量级。 自监督把“没有标注就用不了”变成了“有文本就能学” ，这是 NLP 能吃到互联网规模数据的唯一途径。第 8 讲在语言模型上第一次用到它，本讲把它放大成了整个领域的范式。 东北大学软件学院 · 自然语言处理 10
第 11 页：两阶段流水线：预训练 → 微调（必背图） 环节二 · 知识点讲解 · 考点 【阶段一 · 预训练 Pre-training】 无标注语料 D u （数十亿 ~ 数万亿 token） │ ▼ 自监督损失 L pre （自回归 或 掩码语言模型） 通用底座 θ pre ← 昂贵：数千 GPU 天 │ ─────────┴────────────────────────────────────── │ ▼ 阶段二 · 微调 Fine-tuning 标注数据 D l （数百 ~ 数万条） │ ▼ 任务损失 L task （分类交叉熵 / 序列标注 / 起止指针） 任务模型 θ task ← 便宜：单卡几十分钟 两个阶段的分工 预训练 ：学会语言的一般规律——词形、句法、语义、常识。目标是 泛化 。 微调 ：把规律对齐到具体任务。目标是 专门化 。 两者用不同的数据、不同的损失、不同的规模。 更新的范围有三种 全参数微调 ：底座 + 任务头一起更新（效果最好、成本最高） 只训任务头 ：冻结底座（特征提取，成本最低，效果略弱） 部分微调 / 参数高效微调 ：只训少量新增参数（LoRA 等）——第 13 讲的主角 为什么这个范式这么强 因为它把 “学语言”与“学任务”解耦 了。学语言需要海量数据与算力，但只需做一次；学任务需要少量标注，可以快速反复做。 这就是下一頁要算的那笔账。 东北大学软件学院 · 自然语言处理 11
第 12 页：成本经济学：昂贵的事只做一次 环节二 · 知识点讲解 · 考点 范式能否成立，取决于一道朴素的算术题 预训练的巨额投入，能被多少次廉价的微调 摊薄 ？ 1 预训练这一侧 语料 ：3.3 B 词（BooksCorpus 约 8 亿 + 英文维基约 25 亿）。 配置 ：batch 256、序列长 512、约 1 M 步（相当于在 33 亿词上训练约 40 轮）。 成本 ：4 天 × 16 块 TPU（BERT-base）；后续更大的模型要数千 GPU 天。 2 微调这一侧 数据 ：数百到数万条标注。 配置 ：学习率 2e-5 ~ 5e-5、2–4 个 epoch。 成本 ：单卡几十分钟到几小时—— 比预训练便宜三个数量级 。 3 这笔账的结论 只要任务数量多、微调次数多， 预训练的一次性投入就被完全摊薄 。 这就是范式成立的经济学基础： 昂贵的事只做一次，便宜的事做一万次 。 而到了 GPT-3，连“便宜的事”都可以省掉——改用提示（第 22 页）。 一个延伸判断： 当你看到“预训练成本极高”时，要追问的是“它被多少下游任务共享” ——成本高不高，取决于摊薄的分母。 东北大学软件学院 · 自然语言处理 12
第 13 页：自回归语言模型（AR）· GPT 路线的目标 环节二 · 知识点讲解 · 考点 链式分解（第 7 讲） P( x₁ , … , x_T ) = ∏ t=1..T P( x t | x₁ … x t−1 ) 自回归预训练目标（负对数似然 ≡ 对真实下一词的交叉熵） L AR = − Σ t=1..T log P( x t | x₁ … x t−1 ; θ ) ① 严格单向 第 t 个位置 只能看左边 （1 … t−1），因果掩码保证这一点（第 11 讲）。 代价：不能双向理解——“银行”是河岸还是金融机构，单向模型只能靠左文判断（除非右文被移到后面）。 ② 信号密度 100% 序列长度 T 就有 T 个监督信号 ——每个位置都是一次“预测下一个词”的训练。 这是 AR 相对 MLM 的一大优势（第 25 页会对比）。 ③ 天然支持生成 训练目标与推理行为 完全一致 ：都是“给定前缀预测下一个”。 所以 AR 模型可以直接写文章、写代码、做对话—— 这正是 decoder-only 最终成为大模型主流的技术原因 。 一句话： 自回归 = 用左边预测右边，每个位置都是一个训练样本，训练什么就会什么 。 东北大学软件学院 · 自然语言处理 13
第 14 页：自编码语言模型（AE）· BERT 路线的目标 环节二 · 知识点讲解 · 考点 掩码语言模型（Masked Language Model, MLM） 以概率 p = 15% 随机选中位置集合 M，按 80 / 10 / 10 策略替换 L MLM = − Σ t ∈ M log P( x t | 上下文 ) └─ 只对 被选中的位置 计算损失 ─┘ ① 条件集合是双向的 预测被挖掉的词时，可以看 除它自己以外的左右全部 上下文。 这带来很强的语义消歧能力：“他把书放在桌子上，因为它太重了”——“它”指书还是桌子，双向信息能帮上忙。 ② 信号密度只有约 15% 只有被选中的位置产生损失：T=512 时约 77 个训练信号 。 所以在同等算力下，MLM 的收敛比 AR 慢——这是它付出的第一笔账。 ③ 不能直接用于生成 训练时输入里有 [MASK] 这个符号，而真实生成时不可能出现 [MASK]。 更根本的是：双向注意力在生成第 t 个词时能看到右边的词——那是“抄答案”。 这就是导入页 Q2 的答案：目标函数决定了能力边界。 东北大学软件学院 · 自然语言处理 14
第 15 页：两张掩码矩阵：单向 vs 双向 环节二 · 知识点讲解 · 考点 因果掩码（GPT / decoder） Q \ K 东 北 大 学 好 东 1 0 0 0 0 北 1 1 0 0 0 大 1 1 1 0 0 学 1 1 1 1 0 好 1 1 1 1 1 行 = 当前 token，列 = 它能看见的 token 实现：softmax 之前给 0 的位置加 −∞， 而不是把权重直接置零（那样会破坏归一化） 双向注意力（BERT / encoder） Q \ K 东 北 大 学 好 东 1 1 1 1 1 北 1 1 1 1 1 大 1 1 1 1 1 学 1 1 1 1 1 好 1 1 1 1 1 右上角的 0 全部消失了 编码器不做生成，因此无需遮蔽未来 → 每个位置的向量都融合了全文信息 要澄清的两点 ① BERT 也不是完全没有掩码 ：它仍然需要屏蔽 padding 位置，只是不需要因果掩码。 ② “双向”与“生成”是不可兼得的 ：双向带来了更强的理解能力，代价是彻底放弃了自回归生成的能力——这就是两个灵魂之问中的 Q2。 东北大学软件学院 · 自然语言处理 15

第 17 页：单向 vs 双向：一次真实的歧义消解 环节二 · 知识点讲解 英文：Winograd 式指代消解 The trophy didn't fit into the suitcase because it was too large. it 指谁？ 答案是 trophy（奖杯）——但判断依据是后面的 too large 。 单向模型 处理 “it” 时只能看左文，不知道后面会说什么，只能猜。 双向模型 能读到 “too large”，于是有足够信息做出正确判断。 中文：同样的机制 他把书放在桌子上，因为 它 太重了。 → “它” = 书 （线索：太重 → 书重） 他把书放在桌子上，因为 它 太乱了。 → “它” = 桌子 （线索：太乱 → 桌子乱） 同一个代词，指代对象由 后半句的性质形容词 决定——这是双向注意力天然擅长的。 所以 BERT 类模型在指代消解、问答、自然语言推断这类 理解任务 上表现突出。 这就把 Q2 的答案讲完了 BERT 之所以“不会说话”，不是因为它的表示不够强，而是因为 双向注意力在生成时能看到答案 。这是一个不可兼得的设计取舍： 要理解就双向，要生成就单向 。而 2020 年之后，随着规模变大，单向路线因为“能生成 + 能扩展 + 能统一所有任务”而胜出——但双向模型在垂直领域判别任务上仍是主力（成本低、可控性强）。 东北大学软件学院 · 自然语言处理 17

第 25 页：MLM 的三笔代价（与后人的两种解法） 环节二 · 知识点讲解 · 考点 1 信号密度低 自回归 ：每个位置都是一次预测 → T=512 时 512 个训练信号（100%） 。 掩码 MLM ：只有被选中的位置计损失 → 约 77 个（15%） 。 后果： 同等算力下 MLM 收敛更慢 ，需要更多训练步数才能达到同样的效果。 2 预训练-微调不一致 预训练输入里有大量 [MASK] ，而下游任务的输入永远是完整文本—— 训练与使用的输入分布不同 。 BERT 用 10% “保持不变”来缓解，但没有根治。这是“预训练-微调差异”（pretrain-finetune discrepancy）的经典例子。 3 被掩码位置相互独立 BERT 假设 15% 的位置可以 彼此独立地 预测——例如同时挖掉“自然”和“语言”时，它不会建模这两个位置之间的依赖。 而事实上它们高度相关。 这是 XLNet 的直接动机 （第 35 页）。 解法 A：ELECTRA —— 把“填空”换成“纠错” 用一个小的生成器把某些词换成 看起来合理的错词 （不是 [MASK]、不是随机词），然后让判别器 逐位置判断“这个词是原文还是被换过的” 。 于是 一条序列的全部 T 个位置都产生监督信号 ，密度从 15% 提升到 100%。这就是 RTD（Replaced Token Detection）的核心。 解法 B：XLNet —— 排列语言模型 洞察：自回归的本质是『按某个顺序连乘』，而 顺序可以任意 。 枚举/采样多种分解顺序（如 x₃ → x₁ → x₄ → x₂），每个位置在 某个顺序下 都能看到左右文，同时保持自回归的形式。 于是既得到双向上下文，又能生成、且没有 [MASK]。 东北大学软件学院 · 自然语言处理 25

第 33 页：变体 ②：ALBERT —— 参数瘦身 环节二 · 知识点讲解 技术一：因式分解嵌入参数化 原版把词表嵌入矩阵设成 V×H（词表大小 × 隐层维度），参数量巨大。 原版： V × H 分解： V × E 再 E × H E ≪ H（如 E=128, H=768） 动机：词嵌入本来就不需要和隐层同维—— 把它压到较小的 E 再投影上去 。 技术二：跨层参数共享 原版每层一套独立的参数；ALBERT 让 所有层共用同一套 。 12 层变 1 层参数——这是参数量下降的主要来源。 反直觉的是：共享之后效果并没有明显变差，说明 Transformer 各层学到的变换有大量共性。 必须澄清的误区：省的是“内存”，不是“时间” ALBERT-xxlarge 约 2.35 亿 参数，比 BERT-large（ 3.34 亿 ）小约 30%，而 GLUE 分数更高（约 89 ）。 但推理速度并没有变快 ：层数一层没减，前向计算量（FLOPs）基本不变，ALBERT-xxlarge 反而比 BERT-large 更慢。 很多论文标题里的“轻量”指的是 参数存储与显存占用 ，不是计算时间——读论文时务必分清。 一个实用的判断 参数量 决定手机部署时的包体大小与内存占用； FLOPs 决定耗电与延迟。 两者是独立的优化目标 ——做端侧部署时必须分别评估，不能只看参数量。 东北大学软件学院 · 自然语言处理 33
第 34 页：变体 ③：ELECTRA 与 DistilBERT 环节二 · 知识点讲解 ELECTRA：把“填空”换成“纠错” 原始： 我 爱 自然 语言 处理 生成器替换： 我 爱 烹饪 语言 处理 ← 看起来合理的错词 判别器逐位置二分类：原/被换？ 原 原 换 原 原 信号密度从 15% 提到 100% ——全部 T 个位置都产生监督。这就是 RTD（Replaced Token Detection）。 三个工程细节 ：①生成器比判别器小得多（1/4 ~ 1/2），因为只用来造负样本；②两者共享词嵌入；③ 小模型上收益尤其明显 ——ELECTRA-Small（1400 万参数）单卡训练 4 天，效果超过 GPT（1.17 亿）。 DistilBERT：知识蒸馏 普通监督： L = CE( softmax(z s ) , y ) ← 只学硬标签「这是正面」 知识蒸馏： L = α · CE( softmax(z s /τ) , softmax(z t /τ) ) + (1−α) · CE( softmax(z s ) , y ) ← 还学教师模型的整个输出分布 τ 是温度，把分布“软化”以暴露类间相似性 让学生模型模仿 教师模型的输出分布 ，而不只是硬标签——软标签携带了“哪些类更容易混”的信息。 结果 ：参数量减少 40% 、速度快 60% 、保留约 97% 的效果。第 14 讲还会展开量化、剪枝、低秩分解等压缩手段。 共同主题： 在“效果—成本”曲线上找到更好的点 ——ELECTRA 改目标提升数据效率，DistilBERT 改模型尺寸换取速度，两者都在回答同一个工程问题。 东北大学软件学院 · 自然语言处理 34
第 35 页：变体 ④：XLNet 与中文变体（WWM / MacBERT） 环节二 · 知识点讲解 XLNet：排列语言模型（PLM） 洞察 ：自回归的本质是“按某个顺序连乘”，而 顺序可以任意 。 普通 AR（唯一顺序）： x₁ → x₂ → x₃ → x₄ 每个位置只能看左边 排列 LM（枚举分解顺序，共 T! 种，实际采样若干）： 取顺序 x₃ → x₁ → x₄ → x₂ → 预测 x₂ 时，x₃ x₁ x₄ 都已出现 → 同时利用了左右文，且保持自回归形式 → 不需要 [MASK] （消除了预训练-微调差异） 中文 WWM：掩码粒度从“字”升到“词” 原版 MLM（字级随机掩码）： 我 喜 欢 学 习 自 然 语 言 处 理 我 喜 欢 [MASK] 习 自 然 语 言 处 理 ← 看到“_习”几乎必然填“学”，任务太简单 WWM（Whole Word Masking，整词掩码）： 我 喜 欢 [MASK] [MASK] 自 然 语 言 处 理 ← 按词边界整词挖掉，任务变难，表示更强 MacBERT ：把 [MASK] 换成 相似词 （MLM as correction），例如“学习”→“研习”，彻底消除预训练与下游之间的输入分布差异，并顺带获得纠错能力。 这一页的三条设计思想 XLNet ：不改变任务形式，只改变 分解顺序 ——用更聪明的数学结构拿双向信息。 WWM ：不改变目标函数，只改变 掩码粒度 ——让任务难度匹配语言结构。 MacBERT ：不改变架构，只改变 替换方式 ——消除训练与使用的分布差异。 三者的共同点：改进往往来自对“任务设计”的思考，而不是堆参数。 东北大学软件学院 · 自然语言处理 35
第 36 页：变体 ⑤：T5 —— 把所有任务统一成“文本 → 文本” 环节二 · 知识点讲解 T5 = Text-to-Text Transfer Transformer：一切任务都写成「输入文本 → 输出文本」 翻译： translate English to German: That is good. → Das ist gut. 分类： sentiment: This movie is great. → positive 相似度：stsb sentence1: A sentence2: B → 3.8 摘要： summarize: 长文章…… → 一段摘要 问答： question: 谁写的？ context: 作者是…… → 作者名 统一了什么 统一输入输出格式 ：都是文本 统一损失函数 ：都是交叉熵 统一解码过程 ：都是自回归生成 统一参数 ：所有任务共享同一个模型 换任务时 只改前缀任务描述 ，不换结构、不换头。 为什么这很关键 在 T5 之前，每个任务都要设计专属的任务头（分类头、标注头、指针头），工程上要维护多套代码。 T5 的思路把“任务适配”从 结构问题 变成了 文本问题 ——这正是后来提示（prompting）的思想雏形。 它的预训练目标（span 掩码）也值得记住：挖掉连续的片段而不是单个词。 历史地位 T5 本身是 encoder-decoder 架构、110 亿参数，在多个基准上达到当时 SOTA。 但更重要的是它把 “统一文本接口” 这个思想推到了极致——今天所有指令微调（第 13 讲）与提示工程（第 14 讲）都建立在这个接口之上。 东北大学软件学院 · 自然语言处理 36
第 37 页：规模法则与涌现：能力是怎么长出来的 环节二 · 知识点讲解 Scaling Law：损失是规模的幂律函数 Kaplan 等 2020：测试损失随规模呈 幂律下降 L(N) ∝ N −α N = 模型参数量 L(D) ∝ D −α D = 训练数据量 L(C) ∝ C −α C = 训练算力 在对数坐标下近似直线 → 可以外推预测 Chinchilla（Hoffmann 等 2022） 给出更优配比：给定算力预算，参数量与训练 token 数应 大致同比例增长 （约 20 token / 参数）——这纠正了早期“只堆参数、数据不够”的做法。 涌现能力：越过阈值后突然出现 某些能力在小模型上 几乎为零 ，超过某个规模后突然出现： 多步推理（算术、逻辑链） 上下文学习 （给几个例子就会做） 指令遵循、格式保持、代码生成 这解释了为什么 GPT-3 能在没有针对任何任务训练的情况下“会做”新任务—— 这些能力不是被专门教出来的，而是规模变大之后自然浮现的。 导入页 Q3 的正式答案 能力不是被『教』出来的，是 随规模长出来的 。这是一个非常重要的观念转变：在预训练时代， “把模型做大 + 把数据喂够”本身就是一种算法 ——它比很多精巧的结构设计更有效。但它也带来新问题：成本、能耗、可复现性、以及“能力到底怎么来的”这个仍未完全解释的问题。 东北大学软件学院 · 自然语言处理 37

第 48 页：本讲小结 环节四 · 小结 1 一个范式 预训练 + 微调 ：两个前提（参数可迁移、标签可自动生成）+ 一笔账（一次性投入被无数次微调摊薄，成本差约三个数量级）。 自监督是它成立的关键： 用规则把无标注数据翻译成有监督样本 。 更新的范围有三种：全参数微调 / 只训任务头 / 参数高效微调。 2 两个目标 AR（GPT） ：单向、信号密度 100%、能生成、训练与推理一致 → decoder-only。 AE（BERT） ：双向、信号密度 15%、不能生成、输入含 [MASK] → encoder-only。 MLM 必考细节 ：15% 掩码 + 80/10/10（80 挖、10 换、10 留）。 3 三条路线与工具 encoder-only 理解（分类/标注/抽取/检索）｜ decoder-only 生成（且成为大模型主流）｜ enc-dec 转换（翻译/摘要）。 变体改的都是配方、参数或目标，不是架构本身 ：RoBERTa 配方、ALBERT 参数、ELECTRA 目标、XLNet 顺序、WWM 粒度。 HuggingFace 三层抽象让 换底座只需改一个字符串 。 一句话带走 昂贵的事只做一次，便宜的事做一万次。 预训练范式把“学语言”与“学任务”解耦，从而让 NLP 第一次吃到了互联网规模的数据。而 GPT-3 之后，连“便宜的事”都开始被省掉——改用提示。下一讲我们就讲：怎么让这个“只会续写”的模型变得 会听话 。 复习索引： 范式两前提与成本账 · AR vs AE 八维对照 · MLM 的 15% 与 80/10/10 · NSP 争议 · 四种任务头 · 微调超参 · BERT/GPT 规格 · 变体六家一句话 。 东北大学软件学院 · 自然语言处理 49
