第 4 讲回响：one-hot 的病，今天来治环节一 · 导入
one-hot 三大死穴
  • 维度灾难：词表 50 万 → 每个词 50 万维稀疏向量
  • 语义鸿沟：任意两词正交，“猫/狗”与“猫/汽车”一样远
  • OOV：词表外无编号（第 4 讲已用子词缓解一半）
词向量的验收标准（学生自己提）
  • ① 低维：几百维足矣，不是几十万维
  • ② 稠密：每个分量都有信息量，不再是 0/1
  • ③ 距离有意义：近义词近、类比可算
核心问题：看不见的“语义”，怎么变成向量空间里可度量的几何？

共现方法：关键假设环节二 · 知识点
教材经典对比例
  • I drink beer. / We drink wine.
  • I guzzle beer. / We guzzle beer.
  • drink 与 guzzle 的上下文分布高度重合 → 它们“同义”
  • 一个类比：颜色 = RGB 组合，词义 = 上下文维度的组合（分布式表示）
三条工程假设
  • ① 窗口内共现即相关——窗口大小是超参数
  • ② 窗口内词序不重要——袋装上下文（与 CBOW 同源）
  • ③ 相似度 = 上下文分布的距离（行向量相似）
核心假设：意义相似 ⇔ 上下文相似——这是计数派与预测派共同的公理。

两种共现：窗口级 vs 文档级环节二 · 知识点
窗口级共现
  • 固定滑动窗口（如 ±2）内出现的词
  • 捕捉局部搭配：形容词+名词
  • 例：“吃”与“苹果”近——word2vec 的原料
文档级共现
  • 同一篇文档内出现的词
  • 捕捉全局主题：股票↔债券、苹果↔发布会
  • LSA 主题模型的原料
数法不同，语义不同：窗口级要搭配，文档级要主题——选错数法，向量就会偏。

PMI 的变体与平滑环节二 · 知识点
变体做法解决什么
PMIlog[P(x,y)/(P(x)P(y))]基准：衡量关联强度
PPMImax(0, PMI)负值噪声截断为 0
平滑 PPMI计数先加 α 再算比值零计数也有定义，低频更稳
PMI² / PMI³对 PMI 取平方 / 立方放大强关联、压制弱关联
所有变体都在回答一个问题：共现统计里，多少是信号、多少是噪声——与第 7 讲平滑同源。

PPMI：奖励“意外的共现”环节二 · 知识点
公式
PMI(x, y) = log [ P(x, y) / (P(x)·P(y)) ] PPMI(x, y) = max(0, PMI(x, y))

分子 P(x,y)：真的共现了多少；分母 P(x)P(y)：按各自频率本该碰巧共现多少。

直觉与效果
  • 比值 ≈1（纯属偶然）→ PMI≈0；比值远大于 1 → PMI 很大
  • 奖励“意外的共现”（苹果 & 甜），惩罚高频虚词（the 跟谁都平平）
  • 负值截断为 0：低频噪声不再捣乱
  • 教材算例：PMI(Say, You)≈1.807，PMI(Say, Goodbye)≈0.807
重要的不是“一起出现得多”，而是“一起出现得出乎意料”——惊喜 = 实际 ÷ 预期。

SVD：把稀疏大矩阵压成稠密向量环节二 · 知识点
做法：计数派的终点
  • PPMI 矩阵是 V×V（几十万 × 几十万），又大又稀疏
  • 做奇异值分解并截断：只留前 d 个主方向（d = 50~300）
  • 每个词取 U 的对应一行 → d 维稠密向量，即潜在语义分析 LSA
天花板
  • 太贵：几十万阶矩阵做 SVD，时间与内存都吃紧
  • 词表固定：新词出现就得重建矩阵、重新分解
  • 语料一变就要推倒重算（不能增量更新）
  • 这是“计数派”的终点，也是范式转换的起点
低秩近似：只保留前 d 个奇异值，等于用“最重要的 d 个方向”近似整个共现矩阵——奇异值大 = 该方向承载的语义差异多。类比拍照压缩：一张图 = 若干张基础图按权重相加，只留权重最大的几张，图片大体不变、存储骤减。d 越大保真越高，但向量越稀疏难学，d = 50~300 是经验甜点。
能不能不建矩阵，直接把向量“学”出来？——word2vec 登场。

word2vec：从“计数”到“预测”环节二 · 知识点
计数派（旧）
  • 全语料 → 建共现矩阵 → PPMI → SVD → 向量
  • “先记账，后总结”——矩阵是中间产物，贵且笨
预测派（word2vec, 2013）
  • 不建矩阵：词向量直接作为模型参数，用“预测邻居”任务训练
  • 向量是任务的副产品——边猜边学
  • Skip-gram：中心词→预测上下文；CBOW：上下文（平均）→预测中心词
来源：Mikolov et al. (2013, Google)；官方预训练 300 维 × 300 万词（约 16 亿词语料）。
思想史地位：自监督学习的第一次大规模成功——监督信号从文本自身免费构造，第 12 讲 BERT 是它的直系后代。
东北大学软件学院 · 自然语言处理12
CBOW：用上下文猜中心词环节二 · 知识点
任务：上下文 → 中心词（多对一）
  • 4 个上下文词各取 one-hot → 查 W 得词向量 → 求平均得 h
  • h 经 W′ 与 softmax 得到 V 个词的概率，目标是让“喜欢”的概率最大
  • Bag-of-Words：上下文不看顺序，装一袋平均——所以“我 爱 你”与“你 爱 我”对它没区别
特点与代价
  • 快：每个窗口只做 1 次预测（1 个训练样本），适合中小语料
  • 代价：输出层要对整个词表做 softmax，V 很大时很慢（→ 负采样）
  • 高频词学得更充分；上下文被平均，细粒度语序信息丢失
  • 记忆钩子：CBOW = Continuous Bag-of-Words——“一群人猜你”
把周围的词装进一个袋子平均一下，去猜中间那个是谁——这就是 CBOW。
东北大学软件学院 · 自然语言处理13
Skip-gram：用中心词猜周围词环节二 · 知识点
任务与目标
  • 给中心词 c，预测窗口 ±k 内每个上下文词 o（一对多）
  • 目标：max Σj log P(wt+j | wt)；每个位置一次 V 类分类
  • P(o | c) = softmax(uo·vc)——点积越大越“亲密”
  • 每个词两套向量：中心词 v、上下文 u（工程上取 v 作为最终词向量）
特点
  • 一个中心词产生 2k 个训练样本（k=2 时 4 个）→ 小语料也能喂饱
  • 对低频 / 稀有词学得更好：每次都被当作目标预测一次
  • 代价：训练更慢；上下文词序也不区分（每个位置是独立任务）
  • 记忆钩子：Skip-gram = “你猜一群人”
CBOW 正推、Skip-gram 反推——方向相反，目标相同：逼出好向量。

负采样：把十万分类换成几个二分类环节二 · 知识点
(w(t), w(t+1)) 正样本 ✓
(w(t), w₁) 负样本 ✗
(w(t), w₂) 负样本 ✗
… 共 k 个负样本
正样本 1 个 + 负样本 k 个
→
σ(u·v)
logistic 二分类：1 或 0
瓶颈与对策
  • softmax 分母对全部 V 个词求和——每样本几十万次 exp，不可行
  • 正样本 (c,o) 记 1；随机采 k 个噪声词（词频 3/4 次方分布）记 0
  • 只更新 k+1 个向量：成本 O(V) → O(k)，k≈5~20
损失与为何有效
L = −log σ(uo·vc) − Σi=1..k log σ(−uwi·vc)

亿次“该不该靠近”的问答雕刻出共现结构；Levy & Goldberg (2014)：负采样隐式分解 PMI 矩阵——与计数派会师。

光给正例会偷懒，有了“假朋友”才学得会区分——不考全场几十万人，只考几个嫌疑人。
东北大学软件学院 · 自然语言处理16
word2vec 训练细节：二次采样与层次 softmax环节二 · 知识点
二次采样 subsampling
  • 高频词按概率丢弃样本：p = 1 − √(t/f)
  • f = 词频（该词出现次数 ÷ 语料总词数）；t = 阈值（论文取 10⁻⁵ 量级，gensim 里是 sample 参数）
  • 只有 f > t 的词才可能被丢；f ≤ t 时 p ≤ 0，不丢弃
  • 例：语料 1000 万词、the 出现 50 万次 → f=0.05；取 t=10⁻⁵ → p=1−√(2×10⁻⁴)≈0.986，即丢掉约 98.6% 的 the 样本
层次 softmax：4 个词的 Huffman 树
词频 a=5, b=2, c=1, d=1 —— 每次合并最小的两个 root(9) 0/ \1 a(5) u1(4) 0/ \1 b(2) u2(2) 0/ \1 c(1) d(1) 码字：a=0 b=10 c=110 d=111 P(d) = σ(u_root·v) × σ(u1·v) × σ(u2·v)

高频词短码、低频词长码：4 词的平均二分类次数 ≈ (5×1+2×2+1×3+1×3)/9 ≈ 1.67 次，而 V 类全 softmax 要算 V 次——V 大时 O(V) → O(log V)；与负采样互为替代，不叠加。

加上负采样，这三招把 word2vec 从玩具变成能跑 16 亿词的工程——维度 100–300、窗口 2–10、k=5–20 是经验超参。

gensim 实战：20 行训练词向量环节二 · 知识点
from gensim.models import Word2Vec sents = ["i love deep learning", "i love nlp", "deep learning is fun", "nlp is fun", "the king rules the country", "the queen rules the country"] sents = [s.split() for s in sents] model = Word2Vec(sents, vector_size=100, window=5, min_count=1, sg=1, negative=5, epochs=100) # sg=1: Skip-gram model.wv.most_similar("king", topn=3) # → queen / rules / country model.wv.similarity("nlp", "learning") # 应高于 nlp ↔ country
预期输出
  • king 的邻居：queen / rules / country
  • similarity(nlp, learning) > similarity(nlp, country)
参数旋钮
  • vector_size 维度 · window 窗口 · epochs 轮数
  • sg 选模型（1=Skip-gram / 0=CBOW）· negative 负采样数

句子 / 文档向量的三种做法环节二 · 知识点
1平均池化（先跑的 baseline）
  • 公式：doc = (1/n) · Σᵢ vᵢ——逐维相加、再除以词数
  • 快、无参数；但词序全丢——“我 喜欢 你”与“你 喜欢 我”结果相同
2doc2vec（把文档学成向量）
  • 每篇文档一个可训练向量，与词一起参与预测（PV-DM / PV-DBOW）
  • 保留一点词序；代价：新文档要单独优化，不能直接查表
3SIF 加权平均（性价比之王）
  • 词频越高、权重越小：w = a / (a + p(w))，a 常取 1e-3
  • 再减去第一主成分去掉“通用成分”；简单却常胜过 LSTM
做法怎么算词序新句子 / 新词典型用途
平均池化逐维平均，无参数丢失随时可用（新词要有向量）分类 / 检索的 baseline
doc2vec文档向量参与训练部分保留新文档要重新优化文档聚类、相似推荐
SIF 加权词频加权 + 去第一主成分丢失随时可用句子相似度、语义检索
怎么选：先跑平均池化当 baseline；只关心句子相似度就用 SIF；数据量大、需要稳定文档表示时用 doc2vec。三者都只把词向量当零件——想把词序真正学进去，要等序列模型（第 8 讲 RNN/LSTM）与上下文表示（第 32 页 ELMo、第 12 讲 BERT）。
词向量是零件、句子向量是组装——真正的上下文表示要等 ELMo / BERT（第 12 讲）。

向量算术：机制、评估与“祛魅”环节二 · 知识点
1机制：为什么加减法有效
  • 训练把“共现差异”雕刻成方向：v(女人)−v(男人) 与 v(王后)−v(国王) 几乎平行
  • 于是把一段位移平移到另一个词上，就落在目标附近
  • 评估集：Google analogy 19,544 条（语义 8,869 + 句法 10,675）
2边界：它不是每次都灵
  • 语义类比（国家-首都、货币）通常比句法类比（比较级、复数）更稳
  • 命中率约 6~7 成（word2vec 原论文约 70%），低频词最差
  • 它是统计规律，不是逻辑推理——别把成功类比当成“理解”
3祛魅：偏见与硬伤
  • 偏见：man : programmer :: woman : homemaker（Bolukbasi 2016）——语料偏见原样进向量（第 14 讲伦理案例）
  • 硬伤：“苹果”的水果义与公司义挤在一个向量里——静态向量的天花板，下一页给解法
使用注意：类比的三个词必须都在词表里；不同语料、不同维度训出来的结果差异很大；类比成功只说明共现结构可以平移，不等于模型“理解”了关系。
向量是语料的镜子：镜子不只照见知识，也照见偏见——这是第 14 讲伦理议题的入门案例。

词向量去偏：定位、中和、均衡环节二 · 知识点
1定位：找出“性别轴”
  • 取多组性别词对的差向量求平均：he − she、man − woman、国王 − 王后……
  • 再做归一化，得到统一方向 ĝ（多组平均更稳，单组容易受噪声影响）
  • 直觉：ĝ 就是向量空间里“性别”这条轴
2中和：让中性词不带性别
  • 公式：w′ = w − (w·ĝ)ĝ——把 w 在性别方向上的投影减掉
  • 结果：w′ 与 ĝ 正交，医生、程序员不再偏向任何性别
  • 只对中性词做：『母亲 / 父亲』这类本就含性别的词要保留
3均衡：成对词与中性词等距
  • 目标：‖w′−man‖ ≈ ‖w′−woman‖，即中性词到两边的距离相等
  • 去偏前“程序员”更靠近男，去偏后与男/女等距（见上图示意值）
  • 成对词本身仍保留性别差异（man ≠ woman），只是不再“牵着”中性词
⚠ 局限与提醒：① 去偏后仍可能有残留偏见，用 WEAT 类测试还能探测到；② 去偏会损失一部分与性别相关的真实信息（护理、产科等语料的客观分布）；③ 词向量去偏 ≠ 模型去偏——数据侧平衡与应用侧审计同样必要（第 14 讲）；④ 同类方法还有 Hard Debias、INLP 等，效果与代价各不相同。
词向量是社会语料的统计镜像——去偏是工程手段，不是“洗白”，仍需使用侧审计（第 14 讲伏笔）。

GloVe 手算：一次梯度更新环节二 · 知识点 · 手算
① 例题设定（玩具语料）
  • 3 个词 A / B / C，窗口 1 的共现计数：XAB=4、XAC=2、XBC=1（对称：Xji=Xij）
  • 维度 d=2；α=0.75；xmax=10（论文默认 100，这里便于手算）；学习率 η=0.1
  • 初始参数：wA=(0.5, −0.2)、w̃B=(0.3, 0.6)，偏置全为 0
② 目标值、权重与当前损失（只看 (A,B) 一对）
  • 目标值：log XAB = ln 4 = 1.386
  • 当前点积：wAᵀw̃B = 0.5×0.3 + (−0.2)×0.6 = 0.030
  • 偏差：r = 0.030 − 1.386 = −1.356
  • 权重：f(4) = (4/10)0.75 ≈ 0.503
  • 损失：JAB = f·r² = 0.503 × 1.839 ≈ 0.925
③ 梯度（∂J/∂wᵢ = 2f·r·w̃ⱼ，∂J/∂w̃ⱼ = 2f·r·wᵢ，∂J/∂b = 2f·r） ∂J/∂w_A = 2×0.503×(−1.356)×(0.3, 0.6) = (−0.409, −0.819) ∂J/∂w̃_B = 2×0.503×(−1.356)×(0.5, −0.2) = (−0.682, +0.273) ∂J/∂b_A = ∂J/∂b̃_B = −1.364 ④ 更新（w ← w − η·∂J/∂w） w_A = (0.5, −0.2) − 0.1×(−0.409, −0.819) = (0.541, −0.118) w̃_B = (0.3, 0.6) − 0.1×(−0.682, +0.273) = (0.368, 0.573) b_A = b̃_B = 0 − 0.1×(−1.364) = 0.136 ⑤ 复核：点积 = 0.541×0.368 + (−0.118)×0.573 = 0.132 残差 = 0.132 + 0.136 + 0.136 − 1.386 = −0.982 损失 = 0.503 × 0.982² ≈ 0.485 （0.925 → 0.485，一次更新降约一半）
每对 (i,j) 贡献一次梯度：f(Xij) 压低低频、截断高频——只让“该学的”共现对主导更新；最终词向量取 wi + w̃i。

两套评估标准：内在看相关，外在看任务环节二 · 知识点
内在评估（Intrinsic）：直接测向量本身
  • 词相似度：WordSim-353 的 353 对词都有人工 0~10 分，看它与余弦相似度排序是否一致
  • 类比任务：a : b :: c : d，用 a−b+c 找最近邻，看命中率
  • 快、便宜、可复现——适合先筛掉明显不行的方法
外在评估（Extrinsic）：接到真实任务上
  • 把向量喂给下游任务：文本分类 / NER / 语义检索，看 F1、准确率
  • 最接近真实用途；代价是慢、要标注数据，结论只对这一个任务成立
  • 选型以外在为准——作业 3 就是一次外在评估
内在任务怎么算具体例子看什么指标
词相似度
WordSim-353		 取 353 对词的人工分，与向量的 cos(u,v) 比较排序一致性 tiger–cat 人工 7.35 分（很像）；tiger–book 只有 0.44 分（无关）——向量也该前者远大于后者 Spearman ρ
好模型约 0.6~0.8
类比
Google analogy		 求 a−b+c 的最近邻是否为 d；语义类与句法类各测一半 北京 : 中国 :: 巴黎 : ? → 法国；good : better :: bad : ? → worse 命中率
top-1 / top-3
怎么读这两套标准：内在评估只回答「向量的几何像不像人的语感」，不回答「在下游任务里有没有用」；所以先用它便宜地筛方法，再用外在任务定稿。名词解释：Spearman ρ 是排序相关系数，越接近 1 说明向量的排序越贴近人工排序；命中率 top-1 指最近邻第一个就是正确答案的比例。数据出处：Finkelstein et al. 2001（WordSim-353）· Mikolov et al. 2013（Google analogy 共 19,544 条：语义 8,869 + 句法 10,675）。
内在评估管“快”，外在评估管“准”——先用内在筛方法，再用下游任务定稿。

三个常见误区环节二 · 知识点
1以为向量“自带语义”

真相：语义来自语料。同一算法换语料（新闻 ↔ 微博），“苹果”的邻居就变了——没有“上帝视角的词向量”。

所以：写清“用什么语料、什么方法训的”；换领域就继续预训练。

2以为 word2vec 懂多义

真相：一词一向量。查 most_similar("苹果")，水果词与公司词会混在一簇；要分义项得靠 ELMo / BERT。

所以：歧义词靠上下文表示（第 12 讲），或用领域词表把义项拆开。

3向量近 = 相关/因果

真相：只说明上下文像。similarity("good","bad") 常常也不低（句型相似），但语义相反。

所以：把向量当特征而非结论，最终用下游任务指标验收。

本讲小结环节四 · 小结
1公理

分布式假设：观其伴，知其义——把“意义”的哲学问题换成“分布”的统计问题。

2范式

计数派建矩阵、预测派学参数；负采样证明两者同根。自监督在此首次大规模成功——直通第 12 讲。

3边界

一词一向量的天花板（bank/苹果）引爆 ELMo：词向量从“查表”变“现场算”，预训练时代开场。

一句话带走：词向量不来自词典，来自亿万次“谁和谁是邻居”的问答——语义是分布的几何。
