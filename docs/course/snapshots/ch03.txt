第 7 页：导入之问：graffe 该改成谁？ 环节一 · 导入 用户想打 giraffe ，却打成 graffe ——机器面对四个候选，凭什么选中正确的那一个？ 候选池 graf · graft · grail · giraffe——每个都“长得有点像”，但只有一个是对的。 线索① 相似度 与错词差异最小的候选更可能：giraffe 与 graffe 只差两个字母（距离 2）。 线索② 频率 常用词更可能被“想打”：giraffe 远比其他三个生僻词常见。 纠错 = 相似度 × 频率 （× 上下文，第 7 讲接棒）——本讲先造“相似度”这把尺子。 东北大学软件学院 · 自然语言处理 06

第 9 页：最小编辑距离：定义与来历 环节二 · 知识点 定义 把 X 变成 Y 所需的 最少字符编辑操作数 。三种操作各记代价 1： 插入 （+1 字符）· 删除 （−1 字符）· 替换 （改 1 字符） 加上“相邻交换”就是 Damerau-Levenshtein 距离 关键词是“ 最少 ”——所有路径里代价最小的那条 来历与经典例子 Levenshtein（1965）为纠错编码提出；Damerau（1964）补交换操作 kitten → sitting = 5 ：k→s（2）、e→i（2）、末尾插 g（1）——六步演示的主角 intension → execution = 8 （替换代价 2，教材惯例） 代价是可调旋钮——替换代价 2 相当于把“替换”看成“删 + 插”两步。 编辑距离 = 两个字符串之间的 “最短路径” ：路径上每一步就是一次编辑操作。 东北大学软件学院 · 自然语言处理 08

第 20 页：代码实现与复杂度 环节二 · 知识点 def edit_distance(x, y): m, n = len(x), len(y) d = [[0] * (n + 1) for _ in range(m + 1)] for i in range(m + 1): d[i][0] = i for j in range(n + 1): d[0][j] = j for i in range(1, m + 1): for j in range(1, n + 1): d[i][j] = min( d[i-1][j] + 1, d[i][j-1] + 1, d[i-1][j-1] + (0 if x[i-1] == y[j-1] else 2)) return d[m][n] 复杂度与验证 时间 O(mn) 、空间 O(mn) ，二重循环 验证：kitten→sitting = 5；play→plan = 2（y→n 替换）；flaw→lawn = 2 带回溯：每格加方向指针，从右下走回左上（med_align 原型） 注意： x[i-1]==y[j-1] 的索引偏移是新手最常写错的一处。 一个二重循环的表格—— 用空间换时间 的教科书案例。 东北大学软件学院 · 自然语言处理 18

第 24 页：加权编辑距离与混淆矩阵 环节二 · 知识点 1 为什么加权 键盘邻键更易打错（a↔s 多于 a↔q）；OCR 易把 0 认成 O；统一代价 1 太粗糙，应让代价反映真实分布。 2 混淆矩阵 四类计数： del / ins / sub / trans ——把“人们怎么犯错”统计成表；把递推式里的常数 1 换成对应代价即可。 3 三步估计 收集（错误串, 正确串）对 → 用回溯逐对归类计数 → 按正确字符出现次数归一化得操作概率。 来源： Kernighan, Church & Gale,《A Spelling Correction Program Based on a Noisy Channel Model》, 1990（IBM）。 加权的意义：纠错从“谁 最近 ”升级为“谁 最可能 ”。 东北大学软件学院 · 自然语言处理 20

第 27 页：噪声信道模型 环节二 · 知识点 把打字想成“有噪声的信道”：用户想打 w ，信道把它变成了 x ，纠错 = 反推最可能的 w。 贝叶斯配方 ŵ = argmax P(w | x) = argmax P(x | w) · P(w) P(x|w)：信道模型——想打 w 错成 x 的概率（混淆矩阵） P(w)：语言模型——w 本身有多常见（第 7 讲展开） 来历与直觉 Shannon（1948）噪声信道思想；KCG（1990）首次用于纠错 acress→actress 与 acress→across 距离同为 1：信道打平， 词频决胜 人话：找“又像又常用”的词，两把尺子缺一不可 纠错 = “又像又常见” ——相似度与频率第一次握手。 东北大学软件学院 · 自然语言处理 22
第 28 页：候选生成：acress 的邻居 环节二 · 知识点 对错词 acress 枚举编辑距离 1 的全部邻居，四种操作各有一例： 1 删除 删掉 a → cress （水芹） 2 换位 a/c 互换 → caress （抚摸） 3 替换 r 换成 c → access （访问） 插入与规模 插一个 t → actress （女演员）。edits1 规模 ≈ 词长 × 字母表，edits2 平方级增长；与词典求交后才是真实候选。SymSpell 只生成“删除变体”建索引，把这一步变成毫秒级查找。 生成管召回、排序管精确 ——第 2 讲的 P/R 权衡在此再次出现。 东北大学软件学院 · 自然语言处理 23
第 29 页：打分：两把尺子相乘 环节二 · 知识点 候选 w 信道 P(x|w) 先验 P(w) 直觉解读 caress 高（a/c 换位是常见打字错误） 中 “又像又常见”，教材例子通常胜出 access 中（r→c 替换不算罕见） 中高 有力竞争者，乘积紧随其后 actress 低（多插一个 t 较罕见） 高 先验强但信道弱，乘积被拉低 cress 中（删字母常见） 低 像但太冷门，先验一票否决 说明： acress 为 Jurafsky & Martin 教材经典例；具体数值依赖语料与混淆矩阵，此处给定性对比。 信道管“错得 像不像 ”，先验管“词 常不常用 ”——乘积最大者胜出。 东北大学软件学院 · 自然语言处理 24
第 30 页：real-word 与中文拼写纠错 环节二 · 知识点 英文 real-word：靠上下文 经典例：fifteen minuets → minutes；two off thew → two of the 做法：对可疑词生成候选，用 n-gram / 神经 LM 给整句打分 代价：候选 × 上下文，计算量陡增 中文 CSC：天生是上下文问题 无空格，错误多为 同音字 （公式/公事）与 形近字 （己/已/巳） 词典检测天然失效，检测与纠正都靠语言模型 基准：SIGHAN 系列；主流：拼音感知的 Soft-Masked BERT 来源： Jurafsky & Martin, SLP3 Ch.2；Norvig 2007（thew 示例）；SIGHAN Chinese Spelling Check Bakeoff；Soft-Masked BERT（EMNLP 2020）。 英文纠错“先检测再纠正”，中文纠错 “检测本身就要理解上下文” ——这正是神经与 LLM 方法在中文成为主流的根本原因。 东北大学软件学院 · 自然语言处理 25

第 34 页：Norvig 式完整纠错器：20 行 环节二 · 知识点 def edits1(w): # 距离 1 的四个邻居 splits = [(w[:i], w[i:]) for i in range(len(w)+1)] deletes = [a + b[1:] for a, b in splits if b] trans = [a + b[1] + b[0] + b[2:] for a, b in splits if len(b) > 1] repls = [a + c + b[1:] for a, b in splits for c in letters if b] inserts = [a + c + b for a, b in splits for c in letters] return set(deletes + trans + repls + inserts) def known(words): return set(w for w in words if w in WORD_FREQ) def correct(w): cands = known([w]) or known(edits1(w)) or known(edits2(w)) or [w] return max(cands, key=WORD_FREQ.get) # 词频决胜 先找距离近的、再挑常用的—— 把本讲的 MED 与 P(w) 装进一个能跑的纠错器 ；它输给大模型的地方只有“上下文”。 东北大学软件学院 · 自然语言处理 26
第 35 页：纠错器的评估：检测与纠正分开 环节二 · 知识点 两个 F1，分开报 检测 F1 ：该发现的错误发现了吗？ 纠正 F1 ：被纠正的词改对了吗？改错比不改更糟 例：10 个错词，检出 8、改对 7，还误改 1 个对的——检测 P=8/9、纠正 P=7/8 为什么分开 合在一起看不清问题出在“ 没发现 ”还是“ 改错了 ” LLM 纠错要额外统计 过度纠正率 （本没错却被改） 这是第 2 讲 P/R 在纠错任务上的具体化 检测管“发现”，纠正管“改对”—— 分开报 F1，才能定位病灶 。 东北大学软件学院 · 自然语言处理 27
第 36 页：WER 词错误率：完整算例 环节二 · 知识点 对齐与计算 ref: the cat sat _ hyp: a cat sat on S D=0 I 替换 S=1（the→a），插入 I=1（on），删除 D=0，参考词数 N=3。 WER = (S+I+D) ÷ N = 2 ÷ 3 ≈ 66.7% 三个要点 对齐本身就是 编辑距离的回溯 ——第 12–17 页的六步演示直接复用 WER 可以 超过 100% （插入过多时） 它是第 10 讲机器翻译评测 BLEU 的兄弟指标，期中考点 评测与纠错共用同一把尺子： 对齐 + 计数 ——编辑距离从来不只是“改错字”。 东北大学软件学院 · 自然语言处理 27
