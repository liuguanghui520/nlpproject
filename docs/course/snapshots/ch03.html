纠错无处不在环节一 · 导入

最小编辑距离：定义与来历环节二 · 知识点
定义

把 X 变成 Y 所需的最少字符编辑操作数。三种操作各记代价 1：

  • 插入（+1 字符）· 删除（−1 字符）· 替换（改 1 字符）
  • 加上“相邻交换”就是 Damerau-Levenshtein 距离
  • 关键词是“最少”——所有路径里代价最小的那条
来历与经典例子
  • Levenshtein（1965）为纠错编码提出；Damerau（1964）补交换操作
  • kitten → sitting = 5：k→s（2）、e→i（2）、末尾插 g（1）——六步演示的主角
  • intension → execution = 8（替换代价 2，教材惯例）

代价是可调旋钮——替换代价 2 相当于把“替换”看成“删 + 插”两步。

编辑距离 = 两个字符串之间的“最短路径”：路径上每一步就是一次编辑操作。

字符串度量家族环节二 · 知识点
度量允许操作 / 定义典型用途

怎么算：从暴力到动态规划环节二 · 知识点
暴力枚举：指数级爆炸
  • 每个位置有“删 / 插 / 替 / 不动”多种选择
  • 长度仅 10 的两个词，操作序列组合就达数万条以上
  • 但大量路径会到达同一个中间状态
动态规划的两个前提
  • 最优子结构：最优路径经过中间态 x，则到 x 的那段必为最优
  • 重叠子问题：子问题被反复求解——算一次、存起来、反复用
  • 子问题：D[i][j] = X 前 i 个字符变 Y 前 j 个字符的最小距离
把“枚举所有改法”变成“填一张 n×m 的表”——每格只看左、上、左上三个邻居。

另一种写法：递归 + 备忘录环节二 · 知识点
from functools import lru_cache @lru_cache(maxsize=None) def dist(x, y, i, j): if i == 0: return j # 边界：全插入 if j == 0: return i # 边界：全删除 return min( dist(x, y, i-1, j) + 1, dist(x, y, i, j-1) + 1, dist(x, y, i-1, j-1) + (0 if x[i-1] == y[j-1] else 2)) dist("kitten", "sitting", 6, 7) # → 5
与表格版的关系
  • 两个写法答案一致，只是方向相反：表格自底向上、递归自顶向下
  • 记忆化把指数级递归压回 O(mn)
  • 口诀：动态规划 = 递归 + 缓存；面试常考两种等价写法
同一递推式，两种方向——表格自底向上，递归自顶向下，记忆化让后者同样 O(mn)。

DP 演示⑥：读出对齐与操作序列环节二 · 知识点
对齐（_ 表示空位 gap）
k i t t e n _ s i t t i n g

① k→s 替换（代价 2）　② i 匹配　③ t 匹配　④ t 匹配　⑤ e→i 替换（代价 2）　⑥ n 匹配　⑦ 插入 g（代价 1）

六步回顾
  • ① 定义子问题 D[i][j]
  • ② 初始化第一行、第一列
  • ③ 递推：三邻居取最小
  • ④ 逐行填表，右下角得距离
  • ⑤ 记指针，回溯找路径
  • ⑥ 读出对齐与操作序列

距离 = 2×2 + 1×1 = 5。

距离回答“有多像”，对齐回答“哪里不像、怎么改”——六步走完，任何字符串对都能复现。

代码实现与复杂度环节二 · 知识点
def edit_distance(x, y): m, n = len(x), len(y) d = [[0] * (n + 1) for _ in range(m + 1)] for i in range(m + 1): d[i][0] = i for j in range(n + 1): d[0][j] = j for i in range(1, m + 1): for j in range(1, n + 1): d[i][j] = min( d[i-1][j] + 1, d[i][j-1] + 1, d[i-1][j-1] + (0 if x[i-1] == y[j-1] else 2)) return d[m][n]
复杂度与验证
  • 时间 O(mn)、空间 O(mn)，二重循环
  • 验证：kitten→sitting = 5；play→plan = 2（y→n 替换）；flaw→lawn = 2
  • 带回溯：每格加方向指针，从右下走回左上（med_align 原型）

注意：x[i-1]==y[j-1] 的索引偏移是新手最常写错的一处。

一个二重循环的表格——用空间换时间的教科书案例。

从距离到相似度：归一化环节二 · 知识点
为什么需要归一化
  • 三个词的差距 2 与三十个词的差距 2不是一个量级
  • 公式：sim = 1 − dist ÷ max(len(x), len(y))
  • 输出 0–1、越大越像；difflib 的 ratio() 正是此思路
用在哪
  • 记录去重：sim ≥ 0.85 判为同一实体
  • 匹配与聚类：相似度可比、可排序
  • 阈值的选择——又是第 2 讲的 P/R 权衡
距离回答“差多少”，相似度回答“像多少”——跨长度比较，请用归一化相似度。
东北大学软件学院 · 自然语言处理19
百万词表时怎么办：工程优化环节二 · 知识点
算法的优化
  • 只求距离：滚动数组，空间 O(min(m,n))
  • 要回溯：Hirschberg 分治，仍 O(mn) 时间、O(min(m,n)) 空间
  • 带状剪枝：只关心距离 ≤k → 只算对角线附近 2k+1 宽的带子
工程的优化：减少要比对的词
  • BK-tree（1973）：用三角不等式建索引，整棵子树直接剪掉
  • SymSpell：预处理词表“删除变体”索引，查询端只删不换，百万词表毫秒级候选
  • 思路：把“逐词算 DP”变成“索引查找”
算法课教你 O(mn)，工程课教你“大多数格子根本不用算”——约束条件就是性能来源。
东北大学软件学院 · 自然语言处理19
局部比对：Smith-Waterman环节二 · 知识点
全局 vs 局部
  • 全局（Needleman-Wunsch）：整段对整段，必须从头到尾
  • 局部（Smith-Waterman, 1981）：任意位置开始与结束，找最相似子段
  • 递推区别：D[i][j] = max(0, 三邻居)——允许从 0 重启
应用
  • 长文本里找相似片段（抄袭检测的局部雷同）
  • 基因序列里找保守区域
  • 同一张 DP 表，改一处就换一种语义——算法家族又一佐证
要“整段像”用全局，要“片段像”用局部——一个 max(0, …) 的差别。
东北大学软件学院 · 自然语言处理20
加权编辑距离与混淆矩阵环节二 · 知识点
1为什么加权

键盘邻键更易打错（a↔s 多于 a↔q）；OCR 易把 0 认成 O；统一代价 1 太粗糙，应让代价反映真实分布。

2混淆矩阵

四类计数：del / ins / sub / trans——把“人们怎么犯错”统计成表；把递推式里的常数 1 换成对应代价即可。

3三步估计

收集（错误串, 正确串）对 → 用回溯逐对归类计数 → 按正确字符出现次数归一化得操作概率。

来源：Kernighan, Church & Gale,《A Spelling Correction Program Based on a Noisy Channel Model》, 1990（IBM）。
加权的意义：纠错从“谁最近”升级为“谁最可能”。

拼写纠错：任务与错误类型环节二 · 知识点
非词错误（Non-word）

  • 本讲主战场：纯“形状”问题，不用懂语义
真实词错误（Real-word）
  • three → there 都是合法词，词典查不出
  • 打字错误（their→there）与认知/同音（piece→peace）
  • 必须看上下文——语言模型甚至语义理解
数据：real-word 错误约占拼写错误的 25–40%（Jurafsky & Martin, SLP3 Ch.2）。
通用纠错三步：检测 → 候选生成 → 选择最优；真正的难题是“拼对但用错”。

噪声信道模型环节二 · 知识点
把打字想成“有噪声的信道”：用户想打 w，信道把它变成了 x，纠错 = 反推最可能的 w。
贝叶斯配方
ŵ = argmax P(w | x) = argmax P(x | w) · P(w)

P(x|w)：信道模型——想打 w 错成 x 的概率（混淆矩阵）
P(w)：语言模型——w 本身有多常见（第 7 讲展开）

来历与直觉
  • Shannon（1948）噪声信道思想；KCG（1990）首次用于纠错
  • acress→actress 与 acress→across 距离同为 1：信道打平，词频决胜
  • 人话：找“又像又常用”的词，两把尺子缺一不可
纠错 = “又像又常见”——相似度与频率第一次握手。

对错词 acress 枚举编辑距离 1 的全部邻居，四种操作各有一例：
1删除

删掉 a → cress（水芹）

2换位

real-word 与中文拼写纠错环节二 · 知识点
英文 real-word：靠上下文
  • 经典例：fifteen minuets → minutes；two off thew → two of the
  • 做法：对可疑词生成候选，用 n-gram / 神经 LM 给整句打分
  • 代价：候选 × 上下文，计算量陡增
中文 CSC：天生是上下文问题
  • 无空格，错误多为同音字（公式/公事）与形近字（己/已/巳）
  • 词典检测天然失效，检测与纠正都靠语言模型
  • 基准：SIGHAN 系列；主流：拼音感知的 Soft-Masked BERT
来源：Jurafsky & Martin, SLP3 Ch.2；Norvig 2007（thew 示例）；SIGHAN Chinese Spelling Check Bakeoff；Soft-Masked BERT（EMNLP 2020）。
英文纠错“先检测再纠正”，中文纠错“检测本身就要理解上下文”——这正是神经与 LLM 方法在中文成为主流的根本原因。

中文纠错实例：同音字与形近字环节二 · 知识点
两类高频错误
  • 同音字（拼音输入）：事实/世事、账号/帐号、公式/公事——全是合法词

收口：四代纠错范式对比环节二 · 知识点
范式核心思想优点局限
① 词典 + MED不在词典即错，找距离最近的词简单、快、可解释只纠 non-word，无上下文
② 统计噪声信道argmax P(x|w)·P(w)，候选生成 + 打分有概率依据，候选可排序依赖语料，real-word 难

④ LLM 生成式直接理解并改写文本可变长、改语法、解 real-word过度纠正贵、不确定、需评估
越往下越“聪明”，也越贵越不可控——经典方法没有过时，而是变成了大模型系统里的“零件”（召回、评测、校验）。

Norvig 式完整纠错器：20 行环节二 · 知识点
def edits1(w): # 距离 1 的四个邻居 splits = [(w[:i], w[i:]) for i in range(len(w)+1)] deletes = [a + b[1:] for a, b in splits if b] trans = [a + b[1] + b[0] + b[2:] for a, b in splits if len(b) > 1] repls = [a + c + b[1:] for a, b in splits for c in letters if b] inserts = [a + c + b for a, b in splits for c in letters] return set(deletes + trans + repls + inserts) def known(words): return set(w for w in words if w in WORD_FREQ) def correct(w): cands = known([w]) or known(edits1(w)) or known(edits2(w)) or [w] return max(cands, key=WORD_FREQ.get) # 词频决胜
先找距离近的、再挑常用的——把本讲的 MED 与 P(w) 装进一个能跑的纠错器；它输给大模型的地方只有“上下文”。

纠错器的评估：检测与纠正分开环节二 · 知识点
两个 F1，分开报
  • 检测 F1：该发现的错误发现了吗？
  • 纠正 F1：被纠正的词改对了吗？改错比不改更糟
  • 例：10 个错词，检出 8、改对 7，还误改 1 个对的——检测 P=8/9、纠正 P=7/8
为什么分开
  • 合在一起看不清问题出在“没发现”还是“改错了”
  • LLM 纠错要额外统计过度纠正率（本没错却被改）
  • 这是第 2 讲 P/R 在纠错任务上的具体化
检测管“发现”，纠正管“改对”——分开报 F1，才能定位病灶。

WER 词错误率：完整算例环节二 · 知识点
对齐与计算
ref: the cat sat _ hyp: a cat sat on S D=0 I

替换 S=1（the→a），插入 I=1（on），删除 D=0，参考词数 N=3。

WER = (S+I+D) ÷ N = 2 ÷ 3 ≈ 66.7%

三个要点
  • 对齐本身就是编辑距离的回溯——第 12–17 页的六步演示直接复用
  • WER 可以超过 100%（插入过多时）
  • 它是第 10 讲机器翻译评测 BLEU 的兄弟指标，期中考点
评测与纠错共用同一把尺子：对齐 + 计数——编辑距离从来不只是“改错字”。

本讲小结 · 5 分钟
一个度量、一套六步算法、一个系统配方、一条演进。
  • 建模：三种操作，最少代价
  • 算法：六步 DP——定义·初始化·递推·填表·回溯·对齐

本讲小结环节四 · 小结
1建模

编辑距离把“像不像”变成可计算的数：三种操作、最少代价、度量家族可选。

2算法

六步 DP：定义 → 初始化 → 递推 → 填表 → 回溯 → 对齐，O(mn) 一张表搞定。

3系统

噪声信道 = 候选生成（管召回）× P(x|w)·P(w)（管精确）；LLM 时代四代范式分工而非替代。

一句话带走：先算得像，再猜得对——编辑距离负责前者，语言模型负责后者。
