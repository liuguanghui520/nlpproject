坑 1没见过 = 0 概率

“软件学院 读”这个组合语料里没出现，N-gram 直接给 0。

坑 2记忆只有 n−1 个词

“小王在巴黎生活了十年，所以他精通 ___”

要答出“法语”，得记得 八个词之前的“巴黎”。Trigram 只看前 2 个词，看不见。

坑 3相似上下文不共享

“猫 吃”与“狗 吃”在计数表里是 两个互不相关的格子。

神经语言模型：任务不变，算法换代环节二 · 知识点讲解
任务定义（与第 7 讲一致）
P(w₁…w_T) = ∏t=1..T P(wₜ | w₁ … wₜ₋₁) 估计条件分布：P(wₜ | w₁ … wₜ₋₁)

语言模型要回答的问题一个字都没变：给定上文，下一个词的概率分布是什么？

变的只是“条件概率怎么算”

第 7 讲（计数）

P(猫|我 养 了 一只) = Count(我 养 了 一只 猫) / Count(我 养 了 一只)

本讲（网络）

h = f(词的向量序列)　→　P(·|上文) = softmax(g(h))

1参数形态

离散计数表 → 连续权重矩阵。

2词的形式

孤立编号 → 稠密向量，相似词天然接近。

3零概率

softmax 永远给每个词正概率——零概率灾难消失。

核心思想：把历史压成向量，让相似上下文共享统计环节二 · 知识点讲解
计数：精确匹配的记忆
count(“我 养 了 猫”) / count(“我 养 了”) “我 养 了 狗” → 另一个格子 两行参数之间没有任何共享 没见过 = 0，只能靠平滑借一点
网络：连续函数的泛化
h = f( C(我), C(养), C(了), C(猫) ) C(·)：共享的嵌入表（稠密向量） v(猫) ≈ v(狗) → f 的输出也接近 P(吃 | 我 养 了 狗) > 0
一句话说清“分布式表示”的威力

把每个词放进一个几何空间，把“上文”压成一个点。语义相近的历史，落在相近的位置——于是模型在一处学到的规律，自动迁移到它从未见过的相似句子上。这是统计方法做不到的事。

所以神经 LM 的第一份礼物不是“更强”，而是“会泛化”。

FFN-LM（Bengio 2003）：四个部件环节二 · 知识点讲解
FFN-LM 网络结构（自绘·中文）
嵌入表 C 是共享的

所有词共用一张表；同一个词在窗口的任何位置都用同一个向量——参数共享的第一层含义。

窗口仍是固定的

n−1 个词，与 n-gram 一样。Bengio 治好了稀疏，没治好窗口。

嵌入是“副产品”

C 与预测目标联合训练 → 语义结构自动涌现。第 5 讲 word2vec 的先声。

结构依据：Bengio et al. (2003), JMLR 3:1137–1155, Figure 1；示意图由本课件重绘。
关键洞察：用连续向量代替 one-hot，让“没见过的组合”也有概率。

FFN-LM 公式与参数清单环节二 · 知识点讲解
cₜ = [ C(wₜ₋ₙ₊₁) ; … ; C(wₜ₋₁) ] ← 拼接，d·(n−1) 维 h = tanh( W₁ · cₜ + b₁ ) ← 隐层，H 维 y = W₂ · h + b₂ ← logits，|V| 维 P(wₜ | 上文) = softmax(y) = exp(y_w) / Σv∈V exp(y_v) 训练目标：min L = − Σt log P(wₜ | wₜ₋ₙ₊₁ … wₜ₋₁) ← 交叉熵（第 6 讲回响）
参数形状规模示例（|V|=5 万，d=128，n=4，H=256）
嵌入表 C|V| × d50,000 × 128 = 6.4 M（词 → 向量）
隐层 W₁H × d(n−1)256 × 384 = 0.098 M（输入 → 隐层）

突破与局限：为什么还需要 RNN环节二 · 知识点讲解
三大突破（2003 年的贡献）
  • 泛化：测试困惑度明显优于 trigram 基线，与 n-gram 插值后进一步降低
  • 词向量副产品：C 自带语义结构，相似词在空间中靠近——第 5 讲 embedding 的先声
  • 免计数：模型即参数，不再维护稀疏计数表，也不再需要平滑补丁
三大局限
  • 窗口固定：仍只看 n−1 个词，长程依赖看不见
  • 位置各配权重：“巴黎”在倒数第 3 位和倒数第 20 位走完全不同的权重列——同一条知识要在每个位置重新学一遍
  • 参数随窗口膨胀：W₁ 从 5d×H 涨到 50d×H，看得越远模型越胖、数据越不够
人类是怎么读句子的？

我们不会每个词都回头重读前 n 个词，而是把“读到目前的理解”留在脑子里，读到新词就更新一次。把这个直觉形式化，就是下一节的 RNN。

下一步的目标：让“窗口”变成“状态”——参数不随长度增长，知识在所有位置复用。

RNN 公式：三行核心式子，三组权重环节二 · 知识点讲解 · 考点
aₜ = Wₓₕ · xₜ + Wₕₕ · hₜ₋₁ + bₕ ← 线性组合：新输入 + 旧记忆 hₜ = tanh( aₜ ) ← 新状态（有界） yₜ = Wₕᵧ · hₜ + bᵧ ; pₜ = softmax(yₜ) ← 词表上的预测分布 h₀ = 0（或可学习初值），所有时间步共享同一组 Wₓₕ / Wₕₕ / Wₕᵧ / b
Wₓₕ · 读输入

当前词向量如何进入记忆——“新进来的信息是什么”。形状 d×h。

Wₕₕ · 翻记忆

旧状态如何带到本步——“过去如何影响现在”。形状 h×h，是梯度病的源头。

Wₕᵧ · 做预测

状态如何变成词表分布。形状 h×|V|，通常参数最多。

为什么默认用 tanh 而不是 sigmoid / ReLU
激活值域导数上限在循环中的表现
tanh(−1, 1)1（在 a=0 处）有界 + 零中心，主流选择
sigmoid(0, 1)0.25衰减更快，且非零中心，不利优化
ReLU[0, +∞)1无界，易发散；少数变体尝试过

代码：20 行实现一个最小 RNN环节二 · 知识点讲解
import numpy as np def rnn_step(x, h, W_xh, W_hh, b): """公式直译：hₜ = tanh(Wₓₕxₜ + Wₕₕhₜ₋₁ + b)""" a = W_xh @ x + W_hh @ h + b return np.tanh(a) input_dim, hidden_dim, T = 3, 4, 5 # 小随机初始化（太大的初值会让 tanh 立刻饱和） W_xh = np.random.randn(hidden_dim, input_dim) * 0.01 W_hh = np.random.randn(hidden_dim, hidden_dim) * 0.01 b = np.zeros(hidden_dim) h = np.zeros(hidden_dim) # h₀ = 0 xs = np.random.randn(T, input_dim) # 5 个词向量 for t, x in enumerate(xs): h = rnn_step(x, h, W_xh, W_hh, b) print(f"t={t+1} |h|={np.linalg.norm(h):.4f} h={np.round(h,3)}")

BPTT：把展开图当深网络，反向沿时间走环节二 · 知识点讲解 · 考点
# 把展开图看成一个 T 层的超深网络：深度 = 句长 前向: x₁→h₁→ŷ₁ ; x₂→h₂→ŷ₂ ; … ; x_T→h_T→ŷ_T 反向: ∂L/∂ŷ_T → ∂L/∂h_T → ∂L/∂h_{T−1} → … → ∂L/∂h₁ 每步同时抽取对 Wₓₕ / Wₕₕ / Wₕᵧ 的局部梯度 最后: ∂L/∂W = Σt=1..T ( ∂Lₜ / ∂W ) ← 参数共享 → 梯度求和
两条回流通路（RNN 独有）

每个 hₜ 都接收两份梯度：

  • 来自当前输出 ŷₜ 的（“这一步预测错多少”）
  • 来自未来状态 hₜ₊₁ 的（“后面的错误有多少要算在我头上”）

正是第二条通路带来了长程依赖——也带来了连乘问题。

两笔账（为什么需要截断）
  • 计算账：完整 BPTT 覆盖所有 (t,k) 对，路径量 O(T²)
  • 内存账：反向需要保存全部 T 步的激活值，长序列显存爆炸

所以工程上几乎不用完整 BPTT——下一页给折中方案。

本质：BPTT = 链式法则 + 参数共享，没有新数学，只有新拓扑。

推导：梯度沿时间连乘 ∏[diag(tanh′)·Wₕₕᵀ]环节二 · 知识点讲解 · 考点
目标：把 t 时刻的损失，回传到 k 时刻的状态（k < t） ① ∂Lₜ/∂h_k = ( ∂Lₜ/∂h_t ) · ( ∂h_t/∂h_k ) ← 链式法则 ② ∂h_t/∂h_k = ∏i=k+1..t ∂h_i / ∂h_{i-1} ← 展开成连乘 ③ 单步雅可比: ∂h_i/∂h_{i-1} = diag( tanh′(a_i) ) · Wₕₕᵀ ④ 合起来: ∂h_t/∂h_k = ∏i=k+1..t [ diag(tanh′) · Wₕₕᵀ ]
两个乘数分别负责什么
  • diag(tanh′)：激活函数的导数，恒 ≤ 1。a 落到饱和区（|a| 大）时导数趋近 0——“饱和即失忆”
  • Wₕₕᵀ：权重矩阵，其最大特征值（谱半径）λ 决定放大还是缩小

二者相乘 k 次 → 指数级变化，不是线性变化。

两个方向，两种病
条件数学后果训练现象
λ·tanh′ < 1梯度 → 0消失：远处学不到，loss 照降不报错
λ·tanh′ > 1梯度 → ∞爆炸：loss 尖峰 / NaN，参数跳飞
考点提示：能写出“两步链式 → 连乘 → 雅可比形式”的推导骨架即可，不要求证明收敛性。

处方一：梯度裁剪——给梯度装“限高杆”环节二 · 知识点讲解
按值裁剪（element-wise）
g_i ← min( max(g_i, −c), c ) 例：g = [3, 4]，c = 1 → g' = [1, 1] ‖g‖ : 5 → √2 ≈ 1.41 方向 : 53° → 45° ← 被扭了

简单粗暴，会改变梯度方向；个别场景（如 CTC 语音识别实践）仍在用。

按范数裁剪（主流，Pascanu 2013）
if ‖g‖ > c: g ← g × ( c / ‖g‖ ) 只缩长度，不改方向——学习信号保住

阈值 c 常用 1 或 5；爆炸是偶发尖峰，裁掉尖峰不伤正常训练。

RNN 训练标配：loss 曲线一有毛刺，先加裁剪。

# PyTorch 一行搞定（放在 loss.backward() 之后、optimizer.step() 之前） loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0) optimizer.step() # 同时监控裁剪前的真实范数，它是训练健康度的体温计 gn = torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0) print(f"grad_norm={gn:.3f}")
边界要说清

裁剪治爆炸，不治消失。

梯度已经接近 0 时，把它放大到阈值是错误操作——常见错误是设一个很大的 c 并以为万事大吉。

什么是“门”
gate = σ( W·[hₜ₋₁ ; xₜ] + b ) ∈ (0, 1)^h 输出 = gate ⊙ 内容 ⊙ = 逐元素乘 每一维一个开度：0 = 全关，1 = 全开 σ 让开度连续可微 → 可以用梯度学习

为什么不用 0/1 硬开关？因为硬开关不可导，梯度传不过去。用 sigmoid 把开关“软化”，是门控能端到端训练的关键。

普通 RNN：每步重写

hₜ = tanh( W·[xₜ, hₜ₋₁] )——记忆被整体覆盖；梯度连乘 diag(tanh′)·Wₕₕᵀ → 消失/爆炸。

LSTM：增量记账

Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ（加法主路）；hₜ = oₜ ⊙ tanh(Cₜ)（对外披露）。梯度回传 ∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)——只乘门值，走得远。

账本 vs 报表

Cₜ 是完整账本（内部长期记忆，不直接对外）；hₜ 是对外报表（按需披露一部分）。“记忆 ≠ 输出”是 LSTM 最关键的一点。

乘法让梯度指数衰减；加法是恒等路径——反向传播中只是一个常数 1。这一思想后来被 ResNet 与 Transformer 反复复用。

演算：一步遗忘
Cₜ₋₁ = [ 0.9, 0.8, −0.6 ] ← 三条旧记忆 fₜ = [ 0.9, 0.1, 1.0 ] ← 本步算出的保留系数 fₜ ⊙ Cₜ₋₁ = [ 0.9×0.9, 0.1×0.8, 1.0×(−0.6) ] = [ 0.81, 0.08, −0.60 ]
逐维解读
  • 第 1 维：0.9 → 0.81，保留九成
  • 第 2 维：0.8 → 0.08，几乎清空
  • 第 3 维：−0.6 → −0.60，原样保留

第 1 维：全量写入 0.50。

第 2 维：写了负值 −0.20——新信息是把这一维往下压。

门是最终的准入控制——内容再强，也过不了关上的门。

对比普通 RNN：hₜ = tanh(...) 是一次全局非线性重写，做不到这种精细分工。

“可加性”的深层意义

Cₜ 与 Cₜ₋₁ 之间是加性关系，不是乘性关系。加性关系在反向传播中的雅可比接近单位阵——误差可以近乎无损地跨越几十上百步。这一条性质，就是 LSTM 能记住长程信息的数学根源。

历史与技巧：遗忘门（2000）与偏置初始化（2015）环节二 · 知识点讲解
1997 原版：没有遗忘门
  • 结构：输入门 + 输出门 + 自环权重恒为 1.0 的记忆单元（constant error carousel）
  • 思路：让误差沿“恒定传送带”无损循环——很聪明的工程直觉
  • 缺陷：C 只进不出，长序列会不断累加直到饱和，模型失去分辨能力

2000 年 Gers 等补上遗忘门，允许主动删除——这才是今天通用的 LSTM。

2015：把遗忘门偏置初始化成 1
# PyTorch：一个几乎没人注意但很关键的初始化 for name, p in lstm.named_parameters(): if 'bias' in name: n = p.size(0) # 门顺序 [input, forget, cell, output] p.data[n//4 : n//2].fill_(1.0) ← 遗忘门偏置 σ(1) ≈ 0.73：默认倾向“保留” σ(0) = 0.5：默认忘掉一半

结构设计给了模型“能力”，工程细节决定这份能力能否被训练出来。同一个 LSTM，b_f=0 和 b_f=1 是两个不同的模型——这也是第 6 讲反复强调的“训练是工程”的回响。

GRU（Cho 2014）：两门一态的减法设计环节二 · 知识点讲解 · 考点
GRU 循环体内部结构（原图·中文）
四行公式
zₜ = σ( W_z xₜ + U_z hₜ₋₁ ) ← 更新门 rₜ = σ( W_r xₜ + U_r hₜ₋₁ ) ← 重置门 h̃ₜ = tanh( W xₜ + U( rₜ ⊙ hₜ₋₁ ) ) ← 候选状态 hₜ = (1−zₜ) ⊙ h̃ₜ + zₜ ⊙ hₜ₋₁ ← 凸组合（Cho 约定）
两个门各管什么

更新门 z：新旧状态各占几成，z 大保留旧记忆、z 小接纳新候选。
重置门 r：算候选时带多少旧记忆，r≈0 表示“翻篇了，只看当前输入”。

为什么能省掉一个门

LSTM 的“遗忘/写入”是两个独立旋钮；GRU 把它们绑成一补一（1−z 与 z），参数少约 25%，效果相当。
经验规律：小数据/试错 → GRU；大数据/精度 → LSTM。

对照 LSTM：谁在控制更新幅度

LSTM 用 f 与 i 两个独立旋钮；GRU 只用一个 z，另一个方向由 1−z 自动决定。

所以 GRU 的状态更新是凸组合：hₜ 永远落在 hₜ₋₁ 与 h̃ₜ 之间，不会跑出区间——数值更稳。

重置门 r 的作用（叠加效果）

r 只影响候选的算法：h̃ₜ = tanh(Wxₜ + U(r⊙hₜ₋₁))。

  • r ≈ 0：候选几乎只由当前输入决定 → “清空旧账重新想”
  • r ≈ 1：带着旧记忆一起算 → “在已有理解上继续推”
一句话：GRU = 用更少的参数，把“记忆保留”和“记忆更新”做成一个旋钮。

两个正交扩展：双向与堆叠环节二 · 知识点讲解
双向 RNN：看得全，但抄不得答案
前向: →hₜ = f( xₜ , →hₜ₋₁ ) t: 1 → T 后向: ←hₜ = f( xₜ , ←hₜ₊₁ ) t: T → 1 表示: hₜ = [ →hₜ ; ←hₜ ] ∈ R^(2h)

为什么需要：“苹果”是水果还是公司，要看右边有没有“发布”“手机”；词性标注要看全句。

关键限制：双向需要完整输入，不能用于自回归生成（生成第 t 个词时不可能知道右边的词）。

两条链的参数是独立的，不是共享的——参数量翻倍。

堆叠 RNN：深度 ≠ 长依赖
第 l 层: h^lₜ = f^l( h^(l−1)ₜ , h^lₜ₋₁ ) 第 1 层的输出序列 → 第 2 层的输入序列 每层参数独立

两个正交的轴：层数 L 增加 → 每步表示更抽象；时间 T → 路径长度不变，仍是 O(T)。

经验：语音识别常用 5–8 层（低层学音素、高层学语义）；NLP 里 2–4 层常见，再深收益递减。

代价：串行计算，层数与时间双重串行，训练慢。

一个必须记住的结论

加层能提升表示的抽象程度，但不能缩短信息在时间上的路径。第 1 个词的信息要影响第 100 个词，无论如何都得经过 99 次接力——这是所有循环结构的共同宿命，也是注意力机制要打破的东西。

注意力的三味药（第 10、11 讲预告）
  • 池化：所有位置一次性矩阵相乘 → 并行，GPU 满载
  • 直连：任意两位置直接连线 → 路径长度 O(1)，不再是 O(距离)
  • 动态：每个位置自己决定看谁、看多少 → 不再依赖固定状态
代价也要说清

没有免费的午餐：RNN 用时间换空间，注意力用空间换时间。

本讲小结环节四 · 小结
1动机与范式

N-gram 数不动的是三件事：稀疏（没见过就是 0）、无泛化（相似上下文不共享）、固定窗口（看不见远处）。

Bengio 2003 的路子：稠密向量 + 函数拟合——从“查表”到“学函数”。

2结构与训练

RNN 用参数共享换任意长记忆：hₜ = tanh(Wₓₕxₜ + Wₕₕhₜ₋₁ + b)，标签就是下一个词（自监督）。

代价是 BPTT 的连乘结构：梯度消失（沉默）与爆炸（响亮）。裁剪治爆炸，门控治消失。

3边界与去向

LSTM 用加法主路 + 逐维门控把记忆变成可学习的决策（∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)），有效记忆约 200 词。

但串行瓶颈与路径 O(距离) 是循环结构的宿命——这就是第 10、11 讲的动机。

一句话带走

你学的不是几个公式，而是一条“为治病而设计结构”的工程思路：先诊断（梯度连乘），再设计（加法主路 + 门控），最后把成功的设计思想复用到更大的系统里（注意力、残差、SwiGLU）。

使用约定：RNN 状态用 tanh；LSTM 三个门用 σ、候选用 tanh；GRU 采用 Cho 2014 约定 hₜ = (1−zₜ)⊙h̃ₜ + zₜ⊙hₜ₋₁。
① 前向：FFN-LM 与 RNN
FFN-LM c = [C(wₜ₋ₙ₊₁); … ; C(wₜ₋₁)] h = tanh(W₁c + b₁) P = softmax(W₂h + b₂) RNN aₜ = Wₓₕxₜ + Wₕₕhₜ₋₁ + bₕ hₜ = tanh(aₜ)，h₀ = 0 pₜ = softmax(Wₕᵧhₜ + bᵧ) 各时间步共享同一组权重
② BPTT 与两种梯度病
单步 ∂hᵢ/∂hᵢ₋₁ = diag(tanh′)·Wₕₕᵀ 跨 k 步 ∂h_t/∂h_k = ∏[diag(tanh′)·Wₕₕᵀ] （∏ 自 i=k+1 连乘到 t） 判据 λ·tanh′ < 1 → 消失（沉默） λ·tanh′ > 1 → 爆炸（响亮） 处方 爆炸 → 按范数裁剪（max_norm=5） 消失 → 换结构（门控）
③ LSTM 一步（三门一候选）
fₜ = σ(W_f [hₜ₋₁;xₜ] + b_f) 遗忘 iₜ = σ(W_i [hₜ₋₁;xₜ] + b_i) 输入 oₜ = σ(W_o [hₜ₋₁;xₜ] + b_o) 输出 C̃ₜ = tanh(W_C [hₜ₋₁;xₜ] + b_C) 候选 Cₜ = fₜ⊙Cₜ₋₁ + iₜ⊙C̃ₜ 账本 hₜ = oₜ⊙tanh(Cₜ) 报表 梯度 ∂Cₜ/∂Cₜ₋₁ ≈ diag(fₜ)
④ GRU 一步（两门一态）
zₜ = σ(W_z xₜ + U_z hₜ₋₁) 更新门 rₜ = σ(W_r xₜ + U_r hₜ₋₁) 重置门 h̃ₜ = tanh(W xₜ + U(rₜ⊙hₜ₋₁)) 候选 hₜ = (1−zₜ)⊙h̃ₜ + zₜ⊙hₜ₋₁ ⚠ 框架常写 hₜ = zₜ⊙h̃ₜ + (1−zₜ)⊙hₜ₋₁ （cuDNN / PyTorch）声明约定再用
